## Stem and Leaf, Introduction to Measures of Central Tendency and Mode

# 1. STEM AND LEAF DISPLAY

### Definition
A Stem-and-Leaf Display is a technique used to sort and display data by dividing each number into two parts: Stem and Leaf.

**Roman Urdu Explanation:**
Is technique mein har number ko 2 parts mein divide karte hain:
- Stem = Starting digit(s)
- Leaf = Remaining digit(s)

**Important Book Points:**
- This technique was introduced by John Tukey in 1977.
- It provides a quick way of sorting and displaying data.
- It preserves the identity of individual observations.
- A vertical line separates Stem and Leaf.

### Example

Number = 243

| Stem | Leaf |
|---|---|
| 2 | 43 |

OR

| Stem | Leaf |
|---|---|
| 24 | 3 |

### Example of Stem and Leaf

Given Data:
12, 18, 26, 27, 29, 30, 31, 35, 37, 39

| Stem | Leaf |
|---|---|
| 1 | 2 8 |
| 2 | 6 7 9 |
| 3 | 0 1 5 7 9 |

**Key Points:**
- Stem represents leading digit(s).
- Leaf represents trailing digit(s).
- Leaves are commonly arranged in ascending order.
- A frequency table does not preserve individual observations in the same way.

**Important:**
Agar sirf Class Interval aur Frequency di ho, to exact leaves find nahi kar sakte. Original observations required hoti hain.

# 2. INTRODUCTION TO MEASURES OF CENTRAL TENDENCY

### Definition
An average is a single value which represents a set of data or a distribution as a whole. It is a central value around which observations tend to cluster.

**Roman Urdu Explanation:**
Average aik single value hoti hai jo poore data ko represent karti hai. Yani bohat sari values ki jagah aik central value data ka overall idea deti hai.

### Measures of Central Tendency
Averages are measures of central tendency.

**Roman Urdu Explanation:**
Central Tendency ka matlab hai data ka centre ya central position.

### Measures of Dispersion
Measures of Dispersion measure the variability of data.

**Roman Urdu Explanation:**
Dispersion batata hai ke data ki values kitni spread ya scattered hain.

### Measure of Location or Position
Average is also called a Measure of Location or Position because it indicates the general position of the distribution on the X-axis.

**Roman Urdu Explanation:**
Average ko Measure of Location bhi kehte hain kyun ke ye X-axis par data ki general position show karta hai.

# 3. MODE

### Definition
Mode is the value which occurs most frequently in a data set.

**Roman Urdu Explanation:**
Jo value data mein sab se zyada baar repeat hoti hai, usay Mode kehte hain.

### Example

Data:
2, 7, 9, 5, 8, 9, 10, 9

9 occurs 3 times.

Mode = 9

## 3.1 No Mode

When no value occurs more frequently than the others, the data may have no mode.

**Roman Urdu Explanation:**
Jab koi aik value baqi values se zyada repeat na ho, to No Mode ho sakta hai.

Example:
2, 4, 6, 8

No Mode

## 3.2 Bi-modal Distribution

A frequency distribution containing two modes is called a Bi-modal Distribution.

**Roman Urdu Explanation:**
Jab data mein do values ki highest frequency equal ho, to usay Bi-modal kehte hain.

Example:
2, 2, 4, 4, 6, 8

Modes = 2 and 4

# 4. MODE IN CASE OF A DISCRETE FREQUENCY DISTRIBUTION

### Definition
In case of a discrete frequency distribution, the mode is the value which has the highest frequency.

**Roman Urdu Explanation:**
Discrete frequency table mein jis X value ki frequency sab se zyada ho, wahi Mode hota hai.

### Example

| X | Frequency (f) |
|---|---:|
| 28 | 1 |
| 33 | 1 |
| 34 | 2 |
| 35 | 3 |
| 36 | 5 |
| 37 | 7 |
| 38 | 10 |
| 39 | 13 |
| 40 | 8 |

Highest Frequency = 13

Mode = 39

# 5. THE MODE IN CASE OF THE FREQUENCY DISTRIBUTION OF A CONTINUOUS VARIABLE

### Definition
In case of grouped data, the modal group is the class interval which has the highest frequency.

**Roman Urdu Explanation:**
Continuous frequency distribution mein jis class interval ki frequency sab se zyada ho, usay Modal Class kehte hain.

Mode formula ki madad se modal class ke andar exact Mode calculate karte hain.

## 5.1 Important Terms

| Symbol | Meaning | Roman Urdu |
|---|---|---|
| l | Lower class boundary of modal class | Modal class ki lower boundary |
| fm | Frequency of modal class | Modal class ki frequency |
| f1 | Frequency of preceding class | Modal class se pehli class ki frequency |
| f2 | Frequency of following class | Modal class ke baad wali class ki frequency |
| h | Length of class interval of modal class | Modal class ki width |

## 5.2 Modal Class

Modal Class woh class hoti hai jiski frequency sab se zyada ho.

Example:
10–19 = 5
20–29 = 8
30–39 = 12
40–49 = 7

Modal Class = 30–39

## 5.3 Lower Class Boundary (l)

Lower boundary modal class ki lower limit se boundary adjustment karke milti hai.

Example:
Modal Class = 30–39

Lower Boundary = 30 - 0.5 = 29.5

## 5.4 Class Width (h)

Class width modal class ki upper boundary aur lower boundary ka difference hota hai.

Formula:
h = Upper Class Boundary - Lower Class Boundary

Example:
h = 39.5 - 29.5
h = 10

# 6. IMPORTANT FORMULAS

## Mode for Continuous Frequency Distribution

Mode = l + [(fm - f1) / ((fm - f1) + (fm - f2))] × h

Where:
- l = Lower class boundary
- fm = Modal class frequency
- f1 = Previous class frequency
- f2 = Next class frequency
- h = Class width

## Class Boundary Adjustment

For whole-number class limits with continuous adjoining classes:

Lower Boundary = Lower Limit - 0.5

Upper Boundary = Upper Limit + 0.5

## Class Width

h = Upper Class Boundary - Lower Class Boundary

# 7. DESIRABLE PROPERTIES OF THE MODE

1. The mode is easily understood and easily ascertained in case of a discrete frequency distribution.

Roman Urdu:
Discrete frequency table mein Mode ko samajhna aur find karna easy hota hai.

2. It is not affected by a few very high or low values.

Roman Urdu:
Kuch bohat high ya low values Mode ko affect nahi kartin.

## When Should We Use the Mode?

Mode is useful when we want to identify the most frequently occurring item or category.

Example:
A clothing store manager can identify the most frequently sold hat size and keep more stock of that size.

Roman Urdu:
Shopkeeper dekh sakta hai ke sab se zyada konsa size sell hota hai, taake us size ka stock zyada rakhe.
