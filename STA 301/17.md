# STA301 – Lecture 17

## 1. Permutation

**Definition:** Permutation is an arrangement of objects in which order matters.

**Roman Urdu:** Cheezon ko arrange karna jahan order important ho.

**Formula:**

nPr = n! / (n-r)!

- n = Total objects
- r = Selected objects
- ! = Factorial

**Example:**

AB and BA are different arrangements.

## 2. Factorial (!)

**Definition:** Factorial is the multiplication of all positive numbers from a number down to 1.

**Roman Urdu:** Number ko us se chhotay tamam positive numbers ke saath 1 tak multiply karna.

**Formula:**

5! = 5 × 4 × 3 × 2 × 1 = 120

**Important:**

0! = 1

1! = 1

## 3. Combination

**Definition:** Combination is a selection of objects in which order does not matter.

**Roman Urdu:** Cheezon ko select karna jahan order important nahi hota.

**Formula:**

nCr = n! / [r! × (n-r)!]

- n = Total objects
- r = Selected objects

**Example:**

AB and BA are the same selection.

## 4. Random Experiment

**Definition:** An experiment whose result cannot be predicted with certainty.

**Roman Urdu:** Aisa experiment jiska result pehle se confirm nahi hota.

**Examples:**
- Tossing a coin.
- Rolling a dice.
- Drawing a card.

## 5. Sample Space

**Definition:** The set of all possible outcomes of an experiment.

**Roman Urdu:** Experiment ke tamam possible results ka group.

**Symbol:** S

**Example:**

Coin toss:

S = {H, T}

Dice roll:

S = {1, 2, 3, 4, 5, 6}

## 6. Events

**Definition:** An event is a subset of the sample space.

**Roman Urdu:** Sample Space mein se kisi particular result ya results ka group Event kehlata hai.

**Example:**

S = {1, 2, 3, 4, 5, 6}

A = {2, 4, 6}

A is an event of getting an even number.

## 7. Mutually Exclusive Events

**Definition:** Events that cannot occur at the same time.

**Roman Urdu:** Aise events jo ek saath occur nahi ho sakte.

**Example:**

A = {2}

B = {5}

**Formula:**

A ∩ B = ∅

Meaning: No common outcome.

## 8. Exhaustive Events

**Definition:** Events that together cover all possible outcomes.

**Roman Urdu:** Aise events jo mil kar tamam possible results cover kar dein.

**Example:**

S = {1, 2, 3, 4, 5, 6}

A = {1, 2, 3}

B = {4, 5, 6}

**Formula:**

A ∪ B = S

Meaning: All outcomes are covered.

## 9. Equally Likely Events

**Definition:** Events that have the same chance of happening.

**Roman Urdu:** Aise results jin ke hone ke chances barabar hon.

**Example:**

Fair coin toss:

P(H) = 1/2

P(T) = 1/2

Both have equal chances.
