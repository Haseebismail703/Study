# DEFINITIONS AND LAWS OF PROBABILITY

## 1. Relative Frequency Definition of Probability

**Definition (Easy English):**

If a random experiment is repeated a large number of times under identical conditions, the probability of an event is the limit of its relative frequency.

**Roman Urdu:**

Agar kisi experiment ko bohat zyada baar repeat kiya jaye, to event jitni baar occur ho uski frequency ko total experiments se divide karte hain. Isay Relative Frequency kehte hain.

### Formula

P(A) = Lim (m/n), as n → ∞

Where:

- P(A) = Probability of event A
- m = Number of times event A occurs
- n = Total number of trials
- n → ∞ = Number of trials increases towards infinity.

**Important Concept:**

As the number of trials increases, relative frequency becomes stable and approaches probability.

Roman Urdu: Jitni zyada baar experiment repeat hoga, relative frequency utni stable hoti jayegi.

### Other Names

1. A Posteriori Definition
2. Empirical Probability
3. Statistical Probability

**Remember:**
- Empirical = Based on observations.
- Statistical = Based on statistical data.
- Long Run = Experiment ko bohat baar repeat karna.

### Example: Coin Tossing (Kerrich, 1946)

Kerrich performed a coin-tossing experiment in Denmark in 1946.

Given:

- Total tosses (n) = 10,000
- Heads (m) = 5,067
- Tails = 4,933

**Find Relative Frequency of Heads.**

Step 1: Formula

Relative Frequency = Number of occurrences / Total trials

Step 2: Put values

= 5,067 / 10,000

Step 3: Answer

= 0.5067

**Answer = 0.5067**

Roman Urdu: 10,000 tosses mein Head 5,067 baar aya. Is liye relative frequency 0.5067 hai.

### Important MCQ Points

- Person = Kerrich
- Year = 1946
- Location = Denmark
- Total tosses = 10,000
- Heads = 5,067
- Tails = 4,933
- Relative frequency of heads = 0.5067

## 2. Axiomatic Definition of Probability

**Definition (Easy English):**

Axiomatic probability is based on three basic rules or axioms of probability.

**Roman Urdu:**

Probability ko calculate karne ke liye 3 basic rules banaye gaye hain. In rules ko Axioms kehte hain.

### Axiom 1: Probability Lies Between 0 and 1

**Formula:**

0 ≤ P(E) ≤ 1

**Easy English:**

The probability of any event lies between 0 and 1.

**Roman Urdu:**

Kisi bhi event ki probability 0 se kam aur 1 se zyada nahi ho sakti.

- P(E) = 0 → Impossible event
- P(E) = 1 → Certain event
- P(E) = 0.5 → Equal chance

Example:

Dice par 7 aane ki probability = 0 (six-sided dice).

### Axiom 2: Probability of a Sure Event

**Formula:**

P(S) = 1

**Easy English:**

The probability of a sure event is always 1.

**Roman Urdu:**

Jo event lazmi hona hai, uski probability hamesha 1 hoti hai.

Example:

Dice roll karne par 1, 2, 3, 4, 5 ya 6 mein se koi number zaroor ayega.

Therefore:

P(S) = 1

### Axiom 3: Mutually Exclusive Events

**Definition (Easy English):**

Two events are mutually exclusive if they cannot occur at the same time.

**Roman Urdu:**

Aise 2 events jo aik hi waqt mein occur nahi ho sakte, unko Mutually Exclusive kehte hain.

**Formula:**

P(A ∪ B) = P(A) + P(B)

Where:

- A ∪ B = A or B
- P(A) = Probability of event A
- P(B) = Probability of event B

**Example:**

A dice is rolled.

A = Getting 2

B = Getting 5

P(A) = 1/6

P(B) = 1/6

Since both cannot occur at the same time:

P(A ∪ B) = P(A) + P(B)

= 1/6 + 1/6

= 2/6

= 1/3

**Answer = 1/3**

Roman Urdu: Aik dice roll mein 2 aur 5 aik saath nahi aa sakte. Is liye dono probabilities add karenge.

## 3. Law of Complementation

**Definition (Easy English):**

The probability of an event not occurring is equal to 1 minus the probability of that event occurring.

**Roman Urdu:**

Kisi event ke na hone ki probability nikalne ke liye us event ki probability ko 1 se minus karte hain.

### Formula

P(A') = 1 − P(A)

Where:

- P(A) = Probability of event A
- P(A') = Probability of event A not occurring
- A' = Complement of A

### Example

A coin is tossed. Find the probability of NOT getting Head.

Step 1: Given

P(A) = 1/2

Step 2: Formula

P(A') = 1 − P(A)

Step 3: Put values

= 1 − 1/2

= 2/2 − 1/2

= 1/2

**Answer = 1/2**

Roman Urdu: Agar Head na aaye to Tail aayega. Is liye Not Head ki probability 1/2 hai.

### Important MCQ Point

- Complement means opposite event.
- A' means not A.
- P(A) + P(A') = 1.
- Probability of impossible event = 0.
- Probability of certain event = 1.

## 4. Addition Law of Probability

**Definition (Easy English):**

The Addition Law is used to find the probability of event A or event B occurring.

**Roman Urdu:**

Jab humein A ya B mein se kisi aik event ke hone ki probability nikalni ho, to Addition Law use karte hain.

### Formula

P(A ∪ B) = P(A) + P(B) − P(A ∩ B)

Where:

- P(A) = Probability of event A
- P(B) = Probability of event B
- P(A ∩ B) = Probability of both A and B occurring.
- A ∪ B = A or B
- A ∩ B = A and B

### Example

Given:

P(A) = 0.5

P(B) = 0.4

P(A ∩ B) = 0.2

Find P(A ∪ B).

Step 1: Write formula

P(A ∪ B) = P(A) + P(B) − P(A ∩ B)

Step 2: Put values

= 0.5 + 0.4 − 0.2

Step 3: Calculate

= 0.9 − 0.2

= 0.7

**Answer = 0.7**

Roman Urdu: Dono events ki probability add karenge, lekin jo common part hai usay aik baar minus karenge kyun ke woh do baar count ho raha hota hai.

### Special Case: Mutually Exclusive Events

Agar A aur B mutually exclusive hon, to:

P(A ∩ B) = 0

Therefore:

P(A ∪ B) = P(A) + P(B)

Yani mutually exclusive events mein intersection zero hota hai.

# IMPORTANT DIFFERENCES FOR MCQs

## 1. Relative Frequency vs Classical Probability

**Classical Probability:**
- Based on equally likely outcomes.
- Formula = Favorable outcomes / Total outcomes.

**Relative Frequency:**
- Based on actual observations.
- Formula = Number of occurrences / Total trials.
- Uses repeated experiments.

## 2. Mutually Exclusive vs Non-Mutually Exclusive

**Mutually Exclusive:**
- Events cannot occur together.
- P(A ∩ B) = 0.
- Formula: P(A ∪ B) = P(A) + P(B).

**Non-Mutually Exclusive:**
- Events can occur together.
- P(A ∩ B) is not zero.
- Formula: P(A ∪ B) = P(A) + P(B) − P(A ∩ B).

## 3. Complement vs Addition Law

**Complement Law:**
- Opposite of an event.
- Formula: P(A') = 1 − P(A).

**Addition Law:**
- Probability of A or B.
- Formula: P(A ∪ B) = P(A) + P(B) − P(A ∩ B).
