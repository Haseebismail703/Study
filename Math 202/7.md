# MTH202 – Lecture 7: SET THEORY

## 1. Set

**Definition:** A well-defined collection of distinct objects is called a Set.

**Roman Urdu:** Aisi collection jisme clearly defined aur different objects hon, usay Set kehte hain.

**Example:** A = {1, 2, 3, 4}

## 2. Elements / Members

**Definition:** The objects inside a set are called its elements or members.

**Roman Urdu:** Set ke andar mojood objects ko Elements ya Members kehte hain.

**Example:** A = {1, 2, 3}  
Elements = 1, 2, 3

## 3. Membership Symbols

| Symbol | Easy English | Roman Urdu |
|---|---|---|
| ∈ | Belongs to | Set ka member hai |
| ∉ | Does not belong to | Set ka member nahi hai |

**Example:**

A = {1, 2, 3}

- 2 ∈ A
- 5 ∉ A

## 4. Three Forms of Sets

### A. Tabular Form

**Definition:** Listing all elements of a set inside curly brackets.

**Roman Urdu:** Set ke tamam elements ko `{ }` mein likhna.

**Example:** A = {1, 2, 3, 4, 5}

### B. Descriptive Form

**Definition:** Describing the elements of a set in words.

**Roman Urdu:** Set ke elements ko words mein explain karna.

**Example:** A = Set of first five natural numbers.

### C. Set Builder Form

**Definition:** Representing a set by using a common condition of its elements.

**Roman Urdu:** Set ke elements ki common condition likhna.

**Example:** A = {x ∈ N | x ≤ 5}

Meaning: x is a natural number less than or equal to 5.

## 5. Sets of Numbers

| Name | Symbol | Easy Meaning |
|---|---|---|
| Natural Numbers | N | Counting numbers: 1, 2, 3... |
| Whole Numbers | W | Natural numbers + 0 |
| Integers | Z | Negative, zero and positive numbers |
| Even Integers | E | Numbers divisible by 2 |
| Odd Integers | O | Integers not divisible by 2 |
| Prime Numbers | P | Numbers having exactly two positive factors |
| Rational Numbers | Q | Numbers written as p/q, q ≠ 0 |
| Irrational Numbers | Q′ | Numbers not expressible as p/q |
| Real Numbers | R | Rational + Irrational numbers |
| Complex Numbers | C | Numbers in the form x + iy |

**Examples:**

- Natural: {1, 2, 3, ...}
- Whole: {0, 1, 2, 3, ...}
- Integers: {..., -2, -1, 0, 1, 2, ...}
- Even: {0, ±2, ±4, ...}
- Odd: {±1, ±3, ±5, ...}
- Prime: {2, 3, 5, 7, 11, ...}
- Rational: 1/2, 3/4, 5
- Irrational: √2, √3, π
- Complex: 3 + 2i

## 6. Subset

**Definition:** A set A is a subset of B if every element of A is also in B.

**Roman Urdu:** Agar A ke tamam elements B mein mojood hon to A, B ka Subset hai.

**Symbol:** ⊆

**Example:**

A = {1, 2}  
B = {1, 2, 3, 4}

A ⊆ B

**Important:** Every set is a subset of itself.

## 7. Proper Subset

**Definition:** A is a proper subset of B if every element of A is in B and B has at least one extra element.

**Roman Urdu:** A ke tamam elements B mein hon aur B mein kam az kam ek extra element bhi ho.

**Symbol:** ⊂

**Example:**

A = {1, 2}  
B = {1, 2, 3}

A ⊂ B

## 8. Equal Sets

**Definition:** Two sets are equal if they contain exactly the same elements.

**Roman Urdu:** Agar dono sets ke elements same hon to woh Equal Sets hain. Elements ka order matter nahi karta.

**Symbol:** =

**Example:**

A = {1, 2, 3}  
B = {3, 2, 1}

A = B

## 9. Null Set / Empty Set

**Definition:** A set containing no elements is called a Null Set or Empty Set.

**Roman Urdu:** Aisa Set jisme koi element na ho.

**Symbols:** ∅ or { }

**Important:** Empty set is a subset of every set.

∅ ⊆ A

## 10. Universal Set

**Definition:** The set of all elements under consideration is called a Universal Set.

**Roman Urdu:** Kisi question mein consider kiye gaye tamam elements ka Set Universal Set kehlata hai.

**Symbol:** U

**Example:**

A = {1, 2}  
B = {3, 4}  
U = {1, 2, 3, 4}

## 11. Venn Diagram

**Definition:** A graphical representation of sets using circles and regions.

**Roman Urdu:** Sets ko circles aur rectangle ki madad se show karna Venn Diagram hai.

- Rectangle = Universal Set (U)
- Circle = Set
- Overlapping area = Common elements

## 12. Finite Set

**Definition:** A set containing a limited number of distinct elements is called a Finite Set.

**Roman Urdu:** Jis Set ke elements limited hon aur count kiye ja saken.

**Example:** A = {1, 2, 3, 4}

|A| = 4

## 13. Infinite Set

**Definition:** A set that is not finite is called an Infinite Set.

**Roman Urdu:** Jis Set ke elements unlimited hon.

**Example:** A = {1, 2, 3, 4, ...}

## 14. Membership Table

**Definition:** A table showing whether an element belongs to a set or not.

**Roman Urdu:** Aisi table jo batati hai ke element Set mein hai ya nahi.

- 1 = Belongs to the set.
- 0 = Does not belong to the set.

**Complement Membership Table:**

| A | Aᶜ |
|---|---|
| 1 | 0 |
| 0 | 1 |

**Example:**

U = {1, 2, 3, 4, 5}  
A = {1, 2, 3}  
Aᶜ = {4, 5}

## 16. Important Exam Points

1. Every set is a subset of itself.
2. Empty set is a subset of every set.
3. Equal sets have the same elements.
4. Order of elements does not matter.
5. Duplicate elements are counted only once.
6. Empty set is a Finite Set.
7. Natural numbers start from 1.
8. Whole numbers start from 0.
9. Integers include negative numbers, zero and positive numbers.
10. Every integer is a rational number.
11. Rational and irrational numbers together form real numbers.
12. A proper subset must have at least one extra element in the larger set.
