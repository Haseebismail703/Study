# MTH202 – Lecture 9: Set Identities (All Laws)

## 1. Idempotent Laws

**Definition:** A set combined with itself gives the same set.

Roman Urdu: Kisi set ko usi set ke saath Union ya Intersection karein to wahi set milta hai.

Formulas:
- A ∪ A = A
- A ∩ A = A

## 2. Commutative Laws

**Definition:** Changing the order of sets does not change the result.

Roman Urdu: Sets ki position change karne se answer change nahi hota.

Formulas:
- A ∪ B = B ∪ A
- A ∩ B = B ∩ A

## 3. Associative Laws

**Definition:** Changing the grouping of sets does not change the result.

Roman Urdu: Brackets ki grouping change karne se answer change nahi hota.

Formulas:
- A ∪ (B ∪ C) = (A ∪ B) ∪ C
- A ∩ (B ∩ C) = (A ∩ B) ∩ C

## 4. Distributive Laws

**Definition:** Union and Intersection distribute over each other.

Roman Urdu: Bracket open karte waqt bahar wala operation dono sets par apply hota hai.

Formulas:
- A ∪ (B ∩ C) = (A ∪ B) ∩ (A ∪ C)
- A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C)

## 5. Identity Laws

**Definition:** Union or Intersection with the empty or universal set gives a fixed result.

Roman Urdu: Empty set aur Universal set ke saath operation karne par specific result milta hai.

Formulas:
- A ∪ ∅ = A
- A ∩ ∅ = ∅
- A ∪ U = U
- A ∩ U = A

## 6. Complement Laws

**Definition:** A set and its complement have no common elements, and together they form the universal set.

Roman Urdu: A aur uske complement ka Intersection empty set hota hai, jabke Union universal set hota hai.

Formulas:
- A ∪ Aᶜ = U
- A ∩ Aᶜ = ∅

## 7. Double Complement Law

**Definition:** The complement of a complement is the original set.

Roman Urdu: Kisi set ka complement dobara nikalne se original set milta hai.

Formula:
- (Aᶜ)ᶜ = A

## 8. De Morgan's Laws

**Definition:** The complement of Union becomes Intersection, and the complement of Intersection becomes Union.

Roman Urdu: Complement lagane se Union, Intersection ban jata hai aur Intersection, Union ban jata hai.

Formulas:
- (A ∪ B)ᶜ = Aᶜ ∩ Bᶜ
- (A ∩ B)ᶜ = Aᶜ ∪ Bᶜ

## 9. Alternative Representation for Set Difference

**Definition:** Set difference can be represented by the Intersection of a set and the complement of another set.

Roman Urdu: A − B ka matlab A ke elements mein se B ke common elements remove karna hai.

Formula:
- A − B = A ∩ Bᶜ

## 10. Subset Laws

**Definition:** A set A is a subset of B if every element of A is also an element of B.

Roman Urdu: Agar A ke saare elements B mein mojood hon to A, B ka subset hai.

Formulas:
- A ⊆ A
- ∅ ⊆ A
- If A ⊆ B and B ⊆ C, then A ⊆ C

## 11. Absorption Laws

**Definition:** These laws simplify set expressions by removing unnecessary parts.

Roman Urdu: Extra expression remove ho jati hai aur result mein A reh jata hai.

Formulas:
- A ∪ (A ∩ B) = A
- A ∩ (A ∪ B) = A

## Quick Revision – Important Keywords

| Law | Keyword |
|---|---|
| Idempotent | Same set |

| Associative | Grouping change |
| Distributive | Expansion |
| Identity | Empty / Universal |
| Complement | Opposite elements |
| Double Complement | Original set |
| De Morgan's | Union ↔ Intersection |
| Set Difference | Remove elements |
| Subset | All elements included |
