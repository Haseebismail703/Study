# MTH202 – Discrete Mathematics

## Lesson 2: Truth Tables, Logical Equivalence and De Morgan’s Law

### 1. Basic Symbols

| Symbol | Meaning |
|---|---|
| \(p, q, r\) | Statements |
| \(\land\) | AND (Aur) |
| \(\lor\) | OR (Ya) |
| \(\neg\) | NOT (Nahi) |
| \(T\) | True |
| \(F\) | False |
| \(\equiv\) | Logically Equivalent (Results same) |

### 2. AND (\(\land\))

**Definition:** AND is true only when both statements are true.

**Example:** Ali studies AND Ali writes.

| p | q | p ∧ q |
|---|---|---|
| T | T | T |
| T | F | F |
| F | T | F |
| F | F | F |

**Roman Urdu:** Dono statements True hon to answer True hota hai. Baqi sab cases mein False.

### 3. OR (\(\lor\))

**Definition:** OR is false only when both statements are false.

**Example:** Ali studies OR Ali writes.

| p | q | p ∨ q |
|---|---|---|
| T | T | T |
| T | F | T |
| F | T | T |
| F | F | F |

**Roman Urdu:** Ek bhi statement True ho to answer True hota hai. Sirf dono False hon to answer False.

### 4. NOT (\(\neg\))

**Definition:** NOT reverses the truth value of a statement.

| p | ¬p |
|---|---|
| T | F |
| F | T |

**Example:**

- p = Ali studies.
- ¬p = Ali does not study.

**Roman Urdu:** NOT, True ko False aur False ko True karta hai.

### 5. Truth Tables

**Definition:** A truth table shows all possible truth values of logical statements.

**Number of rows formula:**

`Number of rows = 2ⁿ`

Here, **n = number of statements**.

| Statements | Rows |
|---|---:|
| 1 | 2 |
| 2 | 4 |
| 3 | 8 |
| 4 | 16 |

**Roman Urdu:** Statements ki tadaad ko power mein 2 ke saath use karte hain. Agar 3 statements hon, to \(2^3 = 8\) rows hongi.

### 6. Logical Equivalence

**Definition:** Two logical expressions are equivalent if their final truth table columns are the same.

**Symbol:** `≡`

**Example:**

`¬(¬p) ≡ p`

**Roman Urdu:** Agar dono expressions ke final answers har row mein same hon, to woh logically equivalent hain.

### 7. Double Negation Law

**Formula:**

`¬(¬p) ≡ p`

**Example:**

- p = Ali is happy.
- ¬p = Ali is not happy.
- ¬(¬p) = It is not true that Ali is not happy.

**Roman Urdu:** Do NOT ek doosre ko cancel kar dete hain. Is liye final result original statement jaisa hota hai.

### 8. De Morgan’s Laws

**First Law:**

`¬(p ∧ q) ≡ ¬p ∨ ¬q`

**Second Law:**

`¬(p ∨ q) ≡ ¬p ∧ ¬q`

**Roman Urdu:**

- Bahar NOT ho aur andar AND ho, to AND ko OR mein change karo aur dono statements par NOT lagao.
- Bahar NOT ho aur andar OR ho, to OR ko AND mein change karo aur dono statements par NOT lagao.

**Important:** AND aur OR interchange hote hain, aur har statement ki truth value negate hoti hai.

### 9. Tautology

**Definition:** A tautology is a logical expression that is always True for every possible truth value.

**Formula:**

`p ∨ ¬p`

**Example:** p = True ho ya False, `p OR NOT p` ka result hamesha True hota hai.

| p | ¬p | p ∨ ¬p |
|---|---|---|
| T | F | T |
| F | T | T |

**Roman Urdu:** Final column mein agar har row True ho, to expression **Tautology** hai.

### 10. Contradiction

**Definition:** A contradiction is a logical expression that is always False for every possible truth value.

**Formula:**

`p ∧ ¬p`

| p | ¬p | p ∧ ¬p |
|---|---|---|
| T | F | F |
| F | T | F |

**Roman Urdu:** Statement aur uski NOT value ek saath True nahi ho sakti. Is liye final column mein har answer False hai.

### 11. Contingency

**Definition:** A contingency is a logical expression that is True for some cases and False for other cases.

**Example:** `p ∧ q`

| p | q | p ∧ q |
|---|---|---|
| T | T | T |
| T | F | F |
| F | T | F |
| F | F | F |

**Roman Urdu:** Agar final column mein True aur False dono hon, to expression Contingency hai.

### 12. Exclusive OR (XOR)

**Definition:** XOR is True when the two statements have different truth values.

**Symbol:** `⊕`

| p | q | p ⊕ q |
|---|---|---|
| T | T | F |
| T | F | T |
| F | T | T |
| F | F | F |

**Roman Urdu:** Ek True aur doosra False ho to True. Dono same hon to False.

## Quick Revision in Roman Urdu

- **AND:** Dono True hon to answer True.
- **OR:** Dono False hon to answer False.
- **NOT:** True ko False aur False ko True karta hai.
- **Logical Equivalence:** Dono final columns same hon.
- **Double Negation:** Do NOT cancel ho jate hain.
- **De Morgan’s Laws:** AND aur OR change hote hain; har statement par NOT lagta hai.
- **Tautology:** Final column mein sab True.
- **Contradiction:** Final column mein sab False.
- **Contingency:** Final column mein True aur False dono.
- **XOR:** Different truth values par True.

**Exam tip:** Tautology, Contradiction aur Contingency ke questions mein pehle truth table banao, phir final column check karo.
