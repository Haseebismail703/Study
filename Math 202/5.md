# ARGUMENT

## 1. ARGUMENT

**Definition (Easy English):**

An argument is a list of statements called premises followed by a statement called the conclusion.

**Roman Urdu:**

Argument mein kuch statements di hoti hain jinhein Premises kehte hain. In premises ki madad se hum ek final statement nikalte hain jise Conclusion kehte hain.

**Structure:**

P1 = Premise 1

P2 = Premise 2

P3 = Premise 3

∴ C = Conclusion

**Symbol:**

∴ = Therefore (Is liye)

## 2. PREMISES AND CONCLUSION

**Premises:**

Statements that provide information or reasons.

Roman Urdu: Jo statements humein information ya reason deti hain.

**Conclusion:**

The final statement derived from the premises.

Roman Urdu: Premises ki madad se jo final result nikalta hai usay Conclusion kehte hain.

## 3. VALID ARGUMENT

**Definition (Easy English):**

An argument is valid if the conclusion is true whenever all the premises are true.

**Formula:**

(P1 ∧ P2 ∧ P3 ∧ ... ∧ Pn) → C

This must be a Tautology.

**Roman Urdu:**

Agar tamam premises TRUE hon aur conclusion bhi TRUE ho, to argument valid hota hai.

**Important Rule:**

Jab tamam premises TRUE hon, conclusion bhi TRUE hona chahiye.

## 4. INVALID ARGUMENT

**Definition (Easy English):**

An argument is invalid if the conclusion is false when all the premises are true.

**Roman Urdu:**

Agar tamam premises TRUE hon lekin conclusion FALSE ho, to argument invalid hota hai.

**Important Rule:**

Premises = TRUE

Conclusion = FALSE

Answer = INVALID

## 5. CRITICAL ROWS

**Definition (Easy English):**

Critical rows are those rows where all the premises have truth value TRUE.

**Roman Urdu:**

Truth table mein woh rows jahan tamam premises TRUE hon, unhein Critical Rows kehte hain.

**Remember:**

- All premises TRUE = Critical Row
- Critical rows mein conclusion sab TRUE = Valid
- Kisi bhi critical row mein conclusion FALSE = Invalid

## 6. BOOK EXAMPLE – VALID ARGUMENT

**Question:**

Show that the following argument form is valid.

p → q

p

∴ q

**Solution:**

Step 1: Make the truth table.

| p | q | p → q | p | q |
|---|---|---|---|---|
| T | T | T | T | T |
| T | F | F | T | F |
| F | T | T | F | T |
| F | F | T | F | F |

Step 2: Find Critical Rows.

First row is the only critical row because both premises are TRUE.

Step 3: Check Conclusion.

First row mein conclusion q = TRUE hai.

**Result:**

Therefore, the argument is VALID.

## 7. BOOK EXAMPLE – INVALID ARGUMENT

**Question:**

Show that the following argument form is invalid.

p → q

q

∴ p

**Solution:**

Step 1: Make the truth table.

| p | q | p → q | q | p |
|---|---|---|---|---|
| T | T | T | T | T |
| T | F | F | F | T |
| F | T | T | T | F |
| F | F | T | F | F |

Step 2: Find Critical Rows.

First row and third row are critical rows.

Step 3: Check Conclusion.

Third row mein:

Premises = TRUE

Conclusion p = FALSE

**Result:**

Therefore, the argument is INVALID.

## 8. BOOK EXERCISE – VALID OR INVALID

**Question:**

Use truth table to determine whether the argument form is valid or invalid.

p ∨ q

p → ¬q

p → r

∴ r

**Solution:**

| p | q | r | p ∨ q | p → ¬q | p → r | Conclusion r |
|---|---|---|---|---|---|---|
| T | T | T | T | F | T | T |
| T | T | F | T | F | F | F |
| T | F | T | T | T | T | T |
| T | F | F | T | T | F | F |
| F | T | T | T | T | T | T |
| F | T | F | T | T | T | F |
| F | F | T | F | T | T | T |
| F | F | F | F | T | T | F |

**Result:**

Third critical row mein conclusion TRUE hai.

Fifth critical row mein conclusion TRUE hai.

Sixth critical row mein conclusion FALSE hai.

Therefore, the argument is INVALID.

## 9. WORD PROBLEM

**Book Example:**

If Tariq is not on team A, then Hameed is on team B.

If Hameed is not on team B, then Tariq is on team A.

Therefore, Tariq is not on team A or Hameed is not on team B.

**Solution:**

Let:

t = Tariq is on team A.

h = Hameed is on team B.

**Symbolic Form:**

Premise 1:

¬t → h

Premise 2:

¬h → t

Conclusion:

∴ ¬t ∨ ¬h

**Truth Table:**

| t | h | ¬t → h | ¬h → t | ¬t ∨ ¬h |
|---|---|---|---|---|
| T | T | T | T | F |
| T | F | T | T | T |
| F | T | T | T | T |
| F | F | F | F | T |

**Result:**

First row is a critical row.

Both premises are TRUE but conclusion is FALSE.

Therefore, the argument is INVALID.

---

# IMPORTANT POINTS FOR EXAM

1. Argument = Premises + Conclusion.
2. ∴ = Therefore.
3. Valid Argument = All critical rows have TRUE conclusion.
4. Invalid Argument = At least one critical row has FALSE conclusion.
5. Critical Row = All premises are TRUE.
6. Valid Argument form = Tautology.
