# Lecture 1: Introduction to Programming

## 1.1 What is Programming?

**Definition:** Programming is writing instructions to solve a particular problem.

**Roman Urdu:** Programming ka matlab computer ko step-by-step instructions dena hai taake woh problem solve kar sake.

## 1.2 What is a Program?

**Definition:** A program is a sequence of instructions used to solve a problem.

**Roman Urdu:** Program instructions ka aik sequence hota hai jo computer ko batata hai ke kaam kaise karna hai.

**Example:**
```cpp
int a = 5;
int b = 3;
int sum = a + b;
```

Result: `8`

## 1.3 Importance of Programming

**Definition:** Programming helps us solve problems and automate tasks.

**Roman Urdu:** Programming se hum calculations, websites, applications aur doosre tasks computer se karwa sakte hain.

## 1.4 Skills Needed for Programming

| Skill | Easy English Definition | Roman Urdu |
|---|---|---|
| Problem-solving | Finding a solution to a problem. | Maslay ka hal nikalna. |
| Planning | Deciding steps before starting. | Pehle se steps sochna. |
| Logical thinking | Thinking in a clear and ordered way. | Logic ke saath sochna. |
| Attention to detail | Noticing small but important details. | Choti ghaltiyon ko notice karna. |
| Self-criticism | Checking and improving your own work. | Apne kaam ko check karna. |

## 1.5 Program Design Recipe

Program design recipe ka matlab program likhne se pehle uski planning karna hai.

1. Understand the problem.
2. Identify the input.
3. Identify the expected output.
4. Plan the solution.
5. Write the program.
6. Test the program and correct errors.

**Example:**
- Input: `5, 3`
- Process: `5 + 3`
- Output: `8`

# Lecture 2: Software Categories, History of C and IDE

## 2.1 What is Software?

**Definition:** Software is a set of programs that tells a computer what to do.

**Roman Urdu:** Software programs ka collection hota hai jo computer se different tasks karwata hai.

## 2.2 Types of Software

| Type | Easy English Definition | Examples |
|---|---|---|
| System Software | Software that manages computer hardware and system resources. | Windows, Linux |
| Application Software | Software designed to perform specific user tasks. | MS Word, Calculator |

**Difference:** System software computer ko operate karne mein help karta hai, jabke application software user ke specific tasks perform karta hai.

## 2.3 What is an Operating System (OS)?

**Definition:** An operating system manages computer hardware and software resources.

**Roman Urdu:** OS computer ke hardware aur software ko manage karta hai.

**Examples:** Windows, Linux, macOS.

## 2.4 What is an IDE?

**Full Form:** Integrated Development Environment.

**Definition:** An IDE is software used to write, compile and test programs.

**Roman Urdu:** IDE aik aisa software hai jahan programmer code likhta, compile karta aur test karta hai.

**Example:** Dev-C++.

## 2.5 What is C Language?

**Definition:** C is a general-purpose programming language used to develop software.

**Roman Urdu:** C aik programming language hai jo software aur doosre computer programs banane ke liye use hoti hai.

## 2.6 History of C Language

- **Dennis Ritchie** developed the C programming language at Bell Laboratories.
- C was developed in the early 1970s.
- C is widely used for system programming.

**Important name:** Dennis Ritchie — Developer of C language.

# Lecture 3: Starting to C++

## 3.1 First C++ Program

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "Welcome to Virtual University";
    return 0;
}
```

## 3.2 Explanation of Code

| Code | Easy English | Roman Urdu |
|---|---|---|
| `#include <iostream>` | Includes input/output features. | Input aur output ke features deta hai. |
| `using namespace std;` | Allows standard names without writing `std::`. | `cout` jaise standard names asani se use hote hain. |
| `int main()` | The main function where program execution starts. | Program yahan se start hota hai. |
| `cout` | Displays output on the screen. | Screen par output dikhata hai. |
| `return 0;` | Indicates successful program completion. | Program successfully end hota hai. |

**Important:** VU handouts ke kuch older examples mein `#include <iostream.h>` bhi mil sakta hai. Exam mein apne lecture ke prescribed syntax ko follow karo.

## 3.3 What is a Variable?

**Definition:** A variable is a named memory location used to store data.

**Roman Urdu:** Variable memory mein aik named jagah hoti hai jahan value store hoti hai.

**Example:**
```cpp
int age = 24;
```

- `int` = data type
- `age` = variable name
- `24` = value

## 3.4 What is a Data Type?

**Definition:** A data type specifies the kind of value a variable can store.

**Roman Urdu:** Data type batata hai ke variable kis qisam ka data store karega.

| Data Type | Purpose | Example |
|---|---|---|
| `int` | Whole numbers | `int age = 24;` |
| `float` | Decimal numbers | `float price = 12.5f;` |
| `double` | Decimal values with more precision | `double pi = 3.14159;` |
| `char` | A single character | `char grade = 'A';` |

## 3.5 Variable Declaration

**Definition:** Declaration specifies the name and data type of a variable.

**Roman Urdu:** Variable ka naam aur type define karna declaration hai.

```cpp
int number;
```

## 3.6 Variable Initialization

**Definition:** Initialization gives a variable its initial value.

**Roman Urdu:** Variable banate waqt usko pehli value dena initialization hai.

```cpp
int number = 10;
```

## 3.7 Arithmetic Operators

**Definition:** Arithmetic operators perform mathematical operations.

**Roman Urdu:** Arithmetic operators mathematical calculations karte hain.

| Operator | Meaning | Example |
|---|---|---|
| `+` | Addition | `5 + 2 = 7` |
| `-` | Subtraction | `5 - 2 = 3` |
| `*` | Multiplication | `5 * 2 = 10` |
| `/` | Division | `8 / 2 = 4` |
| `%` | Remainder | `8 % 3 = 2` |

**Important:** Integer division mein decimal part discard ho jata hai.

```cpp
int x = 7 / 2;
```

Answer: `3`, not `3.5`.

## 3.8 Operator Precedence

**Definition:** Operator precedence determines which operation is performed first.

**Roman Urdu:** Expression mein multiple operators hon to precedence batati hai ke pehle konsa operation hoga.

```cpp
int result = 2 + 3 * 4;
```

Answer: `14`, because multiplication comes before addition.

```cpp
int result = (2 + 3) * 4;
```

Answer: `20`, because parentheses are evaluated first.

# Lecture 4: Expressions and Operators

## 4.1 What is an Expression?

**Definition:** An expression combines values, variables and operators to produce a result.

**Roman Urdu:** Expression mein values, variables aur operators mil kar aik result banate hain.

**Example:**
```cpp
int result = a + b * 2;
```

Here, `a + b * 2` is an expression.

## 4.2 What is an Operator?

**Definition:** An operator performs an operation on one or more operands.

**Roman Urdu:** Operator kisi value ya variable par operation perform karta hai.

Example: `a + b`

- `+` = operator
- `a` and `b` = operands

## 4.3 Types of Operators

| Type | Definition | Examples |
|---|---|---|
| Arithmetic | Performs mathematical calculations. | `+`, `-`, `*`, `/`, `%` |
| Relational | Compares two values. | `<`, `>`, `<=`, `>=`, `==`, `!=` |
| Logical | Combines or reverses conditions. | `&&`, `||`, `!` |
| Assignment | Assigns a value to a variable. | `=`, `+=`, `-=` |
| Increment | Increases a variable by one. | `++` |
| Decrement | Decreases a variable by one. | `--` |

## 4.4 Relational Operators

| Operator | Meaning | Example |
|---|---|---|
| `==` | Equal to | `5 == 5` → true |
| `!=` | Not equal to | `5 != 3` → true |
| `>` | Greater than | `5 > 3` → true |
| `<` | Less than | `3 < 5` → true |
| `>=` | Greater than or equal to | `5 >= 5` → true |
| `<=` | Less than or equal to | `3 <= 5` → true |

**Important Difference:**

- `a = 5;` assigns a value to `a`.
- `a == 5` checks whether `a` equals 5.

## 4.5 Logical Operators

| Operator | Meaning | Roman Urdu |
|---|---|---|
| `&&` | AND | Dono conditions true hon. |
| `||` | OR | Kam az kam aik condition true ho. |
| `!` | NOT | Condition ka result reverse karta hai. |

**Example:**
```cpp
int age = 20;
cout << (age >= 18 && age <= 60);
```

Both conditions are true, so output is `1`.

## 4.6 Increment and Decrement

**Increment:** Increases a variable by one.

```cpp
int x = 5;
x++;
```

Result: `x = 6`.

**Decrement:** Decreases a variable by one.

```cpp
int x = 5;
x--;
```

Result: `x = 4`.

### Pre-Increment and Post-Increment

- `++x` = pre-increment
- `x++` = post-increment

Pre-increment increases the value before using it in the expression. Post-increment uses the old value first and then increases it.

```cpp
int x = 5;
int y = x++;
```

Result:
- `y = 5`
- `x = 6`

## 4.7 Assignment Operators

| Operator | Example | Meaning |
|---|---|---|
| `=` | `x = 5` | Assign 5 to x |
| `+=` | `x += 2` | `x = x + 2` |
| `-=` | `x -= 2` | `x = x - 2` |
| `*=` | `x *= 2` | `x = x * 2` |
| `/=` | `x /= 2` | `x = x / 2` |

## 4.8 Operator Precedence

Basic order for these operators:

1. Parentheses `()`
2. Multiplication, division and remainder `* / %`
3. Addition and subtraction `+ -`
4. Relational operators `< > <= >=`
5. Equality operators `== !=`
6. Logical AND `&&`
7. Logical OR `||`
8. Assignment `=`

**Roman Urdu:** Expression solve karte waqt pehle high-priority operators solve karo. Same precedence wale operators ke liye associativity bhi check karo.

# Lecture 5: Decisions

## 5.1 What is Decision Making?

**Definition:** Decision making executes different instructions based on a condition.

**Roman Urdu:** Condition check karke decide hota hai ke konsa code execute hoga.

## 5.2 What is an `if` Statement?

**Definition:** An if statement executes code when a condition is true.

**Roman Urdu:** Agar condition true ho to `if` ke andar wala code execute hota hai.

**Syntax:**
```cpp
if (condition) {
    // statements
}
```

**Example:**
```cpp
int age = 20;

if (age >= 18) {
    cout << "Eligible";
}
```

Output: `Eligible`

## 5.3 What is an `if-else` Statement?

**Definition:** An if-else statement selects between two alternatives.

**Roman Urdu:** Condition true ho to `if` chalega, warna `else` chalega.

```cpp
int number = 5;

if (number > 0) {
    cout << "Positive";
} else {
    cout << "Not positive";
}
```

Output: `Positive`

## 5.4 What is an `else-if` Ladder?

**Definition:** An else-if ladder checks multiple conditions in sequence.

**Roman Urdu:** Multiple conditions ko bari bari check karne ke liye `else if` use hota hai.

```cpp
int marks = 75;

if (marks >= 80) {
    cout << "A";
} else if (marks >= 60) {
    cout << "B";
} else {
    cout << "C";
}
```

Output: `B`

**Important:** Jaise hi koi condition true ho jaye, uska block execute hota hai aur baqi ladder skip ho jati hai.

## 5.5 What is a Nested `if`?

**Definition:** A nested if is an if statement inside another if statement.

**Roman Urdu:** Jab aik `if` ke andar doosra `if` likha jaye to usay nested if kehte hain.

```cpp
int age = 20;
int hasID = 1;

if (age >= 18) {
    if (hasID == 1) {
        cout << "Allowed";
    }
}
```

Output: `Allowed`

## 5.6 What is a Condition?

**Definition:** A condition is an expression that evaluates to true or false.

**Roman Urdu:** Condition check karti hai ke koi baat true hai ya false.

Example: `age >= 18`

- If `age = 20`, the condition is true.
- If `age = 15`, the condition is false.

## 5.7 Difference Between `if` and `if-else`

| `if` | `if-else` |
|---|---|
| Executes code when the condition is true. | Chooses between two alternatives. |
| If false, its block is skipped. | If false, the else block executes. |
