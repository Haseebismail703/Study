# CS101 — Modules 46 to 50

## 46. Operating Systems: Basic Concepts (I)

### Coordination with User
- Interactive processing ka purpose users ko sufficiently fast response dena hai.
- Example: Typing characters in word processing.
- Kuch tasks ko specific deadline ke andar complete karna hota hai.

### Real-time Processing
- Computer performs tasks according to deadlines in the external real-world environment.
- Example: Cruise Missile and Radar.
- Roman Urdu: Computer ko real-world situation ke mutabiq time par task complete karna hota hai.

### Interactive system and Real-time Processing
- Agar system sirf one user ko serve kare, to real-time processing implement karna relatively easy hota hai.
- 1960s aur 1970s mein computers expensive thay, is liye aik machine ko multiple users serve karne parte thay.

### Time Sharing
- **Time-sharing** operating system multiple users ko same time par service provide karta hai.
- Users apne remote terminals se computer use kar sakte hain.
- Figure 52 mein Active, Ready aur Waiting states show ki gayi hain.

### Multi-programming
- Time-sharing implement karne ka aik method hai.
- Har job ko chhota time interval diya jata hai.
- Early systems 30 users ko simultaneously service kar sakte thay.

### Multitasking
- **Multitasking:** One user executing several tasks simultaneously.
- Aaj multiprogramming single-user aur multiple-user systems dono mein use hoti hai.

## 47. Operating Systems: Basic Concepts (II)

### Multiuser and Time-sharing Operating Systems
- Aik large central computer multiple workstations se connected hota hai.
- Users workstations se directly computer communicate kar sakte hain.
- Users ko har request ke liye computer operator ke paas jane ki zaroorat nahi hoti.

### System Administrator
- Computer operator ka role **System Administrator** ne replace kar diya.
- System administrator computer system manage karta hai.

Main responsibilities:
- New hardware aur software installation manage karna.
- User accounts create karna.
- Users ke liye mass storage space limits set karna.
- System problems resolve karne mein coordination karna.

### Evolution of Operating Systems
- Operating systems simple programs se complex systems ban gaye.
- Ye time-sharing coordinate karte hain, programs aur data files maintain karte hain aur users ki requests ka response dete hain.

### Multiprocessor Machines
- Multiple processors different tasks perform kar sakte hain.
- Operating system tasks ko different processors par assign kar sakta hai.

### Load Balancing
- **Load balancing:** Tasks ko dynamically different processors mein allocate karna, taake all processors efficiently use hon.
- Roman Urdu: Kaam processors mein is tarah divide karna ke koi processor unnecessarily idle na rahe.

### Scaling
- **Scaling:** Tasks ko available processors ki number ke mutabiq subtasks mein divide karna.

### Embedded Systems
- Specific tasks ke liye dedicated computer systems ko **Embedded Systems** kehte hain.
- Examples: Medical devices, vehicle electronics, home appliances, cell phones and handheld computers.
- Embedded operating systems battery power save kar sakte hain, real-time deadlines meet karte hain aur little or no human oversight ke sath operate kar sakte hain.

Examples given in handout:
- VxWORKS
- Windows CE (Pocket PC)
- Palm OS

## 48. Operating Systems: Software Classification

Software ki two broad categories hain:

### 1. Application Software
- **Application software:** Programs used to perform tasks particular to a machine's utilization.
- Roman Urdu: Aisa software jo user ka specific kaam perform karta hai.

Examples:
- Spreadsheets
- Database systems
- Desktop publishing systems
- Accounting systems
- Program development software
- Games

### 2. System Software
- **System software:** Performs tasks that are common to computer systems in general.
- It provides the infrastructure required by application software.
- Roman Urdu: Ye computer ke basic system functions handle karta hai aur application software ko support karta hai.

System software has two categories:

**A. Operating System**
- Computer system ko operate aur manage karta hai.

**B. Utility Software**
- Utility software operating system ki capabilities ko extend ya customize karta hai.
- Examples:
  - Disk formatting
  - Copying files from magnetic disk to CD
  - Compressing and decompressing data
  - Playing multimedia presentations
  - Handling network communication

## 49. Operating Systems: Components (I)

### User Interface
- **User interface:** Operating system ka portion jo computer users ke sath communication handle karta hai.
- Roman Urdu: User aur operating system ke darmiyan communication ka zariya.

### Shells
- Older user interfaces ko **shells** kehte hain.
- Ye keyboard aur monitor ke through textual messages se communicate karte thay.

Examples from handout:
- Bourne shell
- C shell
- Korn shell
- X11 GUI

### Graphical User Interface (GUI)
- **GUI:** Files aur programs ko display par icons ki form mein show karta hai.
- Users mouse se icons click ya drag karke commands de sakte hain.
- Touch screens par users fingers se directly icons manipulate kar sakte hain.

GUI examples/features:
- Icons
- Mouse
- Stylus
- Touch screens

### Three-dimensional Interfaces
- 3D projection systems, tactile sensory devices aur surround sound audio systems ke zariye computer se communication research ka subject hai.

### Window Manager
- **Window manager:** Screen par space blocks allocate karta hai jinhein windows kehte hain.
- Ye track karta hai ke kaunsi application kis window se associated hai.
- Mouse click ki location identify karke appropriate application ko inform karta hai.
- GUI ka style manage karta hai.

Examples:
- KDE
- Gnome

## 50. Operating Systems: Components (II)

### Kernel
- **Kernel:** Operating system ka internal part hota hai.
- Is mein software components hotay hain jo computer ke basic functions perform karte hain.

### File Manager
- **File manager:** Computer ki mass storage facilities ko coordinate karta hai.
- Ye records maintain karta hai:
  - Files kahan located hain.
  - Kin users ko files access karne ki permission hai.
  - New files ke liye kitni storage available hai.

### Directory or Folder
- File manager files ko groups mein organize karne ki facility deta hai.
- Is group ko **directory** ya **folder** kehte hain.

### Subdirectories
- Directory ke andar doosri directories ko **subdirectories** kehte hain.
- Is tarah hierarchical organization create hoti hai.

### Directory Path
- Directories ki chain ko **directory path** kehte hain.
- Example: `animals/prehistoric/dinosaurs`
- Windows mein slashes reverse direction mein hotay hain: `animals\prehistoric\dinosaurs`

### Opening a File
- Kisi file ko access karne ke liye file manager se permission request ki jati hai.
- Is procedure ko **opening the file** kehte hain.
- Approval milne par file ko find aur manipulate karne ki information milti hai.

### Device Drivers
- **Device drivers:** Software units jo controllers ya peripheral devices ke sath communicate karte hain.
- Har device driver apne particular device ke liye designed hota hai.
- Examples: Printer, disk drive and monitor.
- Ye generic requests ko device ke required technical steps mein translate karta hai.

### Memory Manager
- **Memory manager:** Computer ki main memory ke use ko coordinate karta hai.
- Multiple programs aur data blocks ko main memory mein manage karta hai.
- Available memory areas ka record maintain karta hai.

### Paging
- Jab required main memory available memory se zyada ho, to memory manager programs aur data ko main memory aur mass storage ke darmiyan move karta hai.
- Is technique ko **paging** kehte hain.

### Pages
- Paging mein data ko equal-sized units mein divide kiya jata hai.
- In units ko **pages** kehte hain.
- Pages typically few KB size ke hotay hain.

### Virtual Memory
- **Virtual memory:** Paging ke through create ki gayi large fictional memory space.
- Example from handout:
  - Required memory = 8 GB
  - Actual main memory = 4 GB
  - Remaining 4 GB space magnetic disk par reserve ki ja sakti hai.
  - Memory manager pages ko main memory aur mass storage ke darmiyan move karta hai.

### Scheduler and Dispatcher
- **Scheduler:** Multiprogramming system mein decide karta hai ke kaunsi activities execution ke liye consider hongi.
- **Dispatcher:** Activities ko time allocate karta hai.
