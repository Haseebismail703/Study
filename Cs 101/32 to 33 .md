# MODULE 32 – Data Manipulation: CPU Basic

## 1. CPU (Central Processing Unit)

**Definition:** CPU is the main processing unit of a computer that performs operations and controls machine activities.

**Roman Urdu:** CPU computer ka processing part hai. Ye data par operations perform karta hai aur computer ki activities control karta hai.

**Important:** CPU consists of three main parts:

1. Arithmetic/Logic Unit (ALU)
2. Control Unit (CU)
3. Register Unit

## 2. Arithmetic/Logic Unit (ALU)

**Definition:** ALU contains circuitry that performs arithmetic and logical operations on data.

**Roman Urdu:** ALU calculations aur logical operations perform karta hai.

### Examples

- Addition (+)
- Subtraction (-)
- AND
- OR

**Remember:** ALU = Performs calculations and logical operations.

## 3. Control Unit (CU)

**Definition:** Control Unit contains circuitry for coordinating the machine's activities.

**Roman Urdu:** Control Unit computer ke different parts ko instructions deta hai aur unke kaam coordinate karta hai.

### Functions

- Controls machine activities.
- Transfers data from memory to registers.
- Tells ALU which operation to perform.
- Tells ALU where to store the result.

**Remember:** CU = Controls and coordinates activities.

## 4. Register Unit

**Definition:** Register unit contains storage cells called registers that temporarily store information inside the CPU.

**Roman Urdu:** Register unit CPU ke andar choti temporary storage locations hoti hain jahan data aur results temporarily store hote hain.

**Remember:** Register Unit = Temporary storage inside CPU.

## 5. Registers

**Definition:** Registers are small storage locations inside the CPU used for temporary storage of data and results.

**Roman Urdu:** Registers CPU ke andar choti storage places hain. CPU calculations ke liye data yahan rakhta hai.

### Types of Registers

1. General-purpose registers.
2. Special-purpose registers.

## 6. General-Purpose Registers

**Definition:** General-purpose registers temporarily hold data being manipulated by the CPU.

**Roman Urdu:** Ye registers calculation ke liye input data aur ALU ke results temporarily store karte hain.

### Functions

- Hold input data for ALU.
- Store results produced by ALU.
- Provide temporary storage.

**Remember:** General-purpose registers = Temporary data and results.

## 7. Special-Purpose Registers

**Definition:** Special-purpose registers are registers designed for specific CPU tasks.

**Roman Urdu:** Ye registers CPU ke specific functions perform karne ke liye use hote hain.

**Important:** In Module 32, the main focus is on general-purpose registers.

## 8. Bus

**Definition:** A bus is a collection of wires that connects the CPU and main memory for transferring bit patterns.

**Roman Urdu:** Bus wires ka collection hota hai jo CPU aur main memory ke darmiyan data transfer karta hai.

### Functions

- Transfers data from memory to CPU.
- Transfers data from CPU to memory.
- Carries memory addresses and control signals.

**Remember:** Bus = Connection between CPU and Main Memory.

## 9. Reading Data from Memory

**Definition:** Reading means retrieving data from a specific memory location.

**Roman Urdu:** CPU memory se data read karta hai. Iske liye CPU memory cell ka address aur read signal provide karta hai.

### Steps

1. CPU provides the memory address.
2. CPU sends a read signal.
3. Memory retrieves the data.
4. Data is transferred to CPU.

## 10. Writing Data into Memory

**Definition:** Writing means storing data in a specific memory location.

**Roman Urdu:** CPU memory mein data save karta hai. Iske liye destination address, data aur write signal provide karta hai.

### Steps

1. CPU provides the destination address.
2. CPU sends the data.
3. CPU sends a write signal.
4. Memory stores the data.

## 11. Adding Two Values Stored in Memory

**Important Concept – Five Steps**

Suppose CPU has to add two numbers stored in main memory.

### Step 1
Get the first value from memory and place it in a register.

### Step 2
Get the second value from memory and place it in another register.

### Step 3
ALU adds both values and stores the result in another register.

### Step 4
Store the result in memory.

### Step 5
Stop.

**Roman Urdu:**

- Step 1: Pehla number memory se register mein lao.
- Step 2: Doosra number doosre register mein lao.
- Step 3: ALU dono numbers add karega.
- Step 4: Result memory mein save hoga.
- Step 5: Process stop ho jayega.

**Remember:** Memory → Registers → ALU → Register → Memory.

# MODULE 33 – Data Manipulation: Stored Program

## 1. Early Computers

**Definition:** Early computers had their instructions built into the control unit.

**Roman Urdu:** Purane computers mein instructions machine ke control unit ka part hoti thi. Program change karna difficult tha.

### Important Points

- Early computers had limited flexibility.
- Instructions were built into the control unit.
- Changing programs was difficult.

## 2. Rewiring of CPU

**Definition:** Some early computers were redesigned so that the CPU could be rewired to change its operations.

**Roman Urdu:** Purane computers mein program change karne ke liye CPU ki wiring change karni parti thi.

### Pegboard Arrangement

**Definition:** A pegboard arrangement was used to connect jumper wires through holes, similar to old telephone switchboards.

**Roman Urdu:** Pegboard ek board hota tha jisme holes hote thay. Jumper wires ko different holes mein lagakar computer ka operation change kiya jata tha.

**Remember:** Pegboard = Rewiring method.

## 3. Stored-Program Concept

**Definition:** The stored-program concept means storing a computer program in its main memory, just like data.

**Roman Urdu:** Program aur data dono main memory mein store hote hain. CPU memory se program ki instructions read karta hai aur execute karta hai.

### Important Points

- Programs are stored in main memory.
- Data is also stored in main memory.
- Control unit extracts instructions from memory.
- Instructions are decoded and executed.
- Programs can be changed by changing memory contents.

**Remember:** Stored Program = Program stored in Main Memory.

## 4. How Stored Program Works

### Step 1: Store Program
Program is stored in main memory.

### Step 2: Extract Instructions
Control unit gets instructions from memory.

### Step 3: Decode Instructions
Control unit interprets the instructions.

### Step 4: Execute Instructions
CPU performs the required operations.

**Roman Urdu:**

Program memory mein save hota hai. Control unit instructions read karti hai, unka meaning samajhti hai aur CPU se un par action karwati hai.

## 5. Advantage of Stored-Program Concept

**Definition:** It allows programs to be changed without rewiring the CPU.

**Roman Urdu:** Ab program change karne ke liye CPU ki wiring change nahi karni parti. Sirf main memory mein stored program change karna hota hai.

### Important Advantages

- More flexibility.
- Easy program changes.
- No need to rewire the CPU.
- Programs and data can both be stored in main memory.

## 6. John von Neumann

**Important MCQ Point:**

The stored-program concept is commonly associated with John von Neumann.

**Roman Urdu:** Stored-program concept ko John von Neumann ke naam se associate kiya jata hai.

**Important Note:** VU handout says that the credit to John von Neumann appears to be incorrect. Isliye agar question pooche "commonly credited to whom?" toh answer John von Neumann hai.

## 7. Early Computer vs Stored-Program Computer

| Early Computers | Stored-Program Computers |
|---|---|
| Instructions built into control unit | Instructions stored in main memory |
| Limited flexibility | More flexibility |
| CPU rewiring was required | Memory contents can be changed |
| Difficult to change programs | Easy to change programs |

## 8. Important Differences

| Term | Meaning |
|---|---|
| ALU | Performs arithmetic and logical operations |
| Control Unit | Coordinates machine activities |
| Register Unit | Temporary storage inside CPU |
| Registers | Small temporary storage locations |
| General-purpose registers | Store input data and results |
| Bus | Connects CPU and main memory |
| Read | Retrieve data from memory |
| Write | Store data in memory |
| Stored-program concept | Program stored in main memory |
| Pegboard | Used for rewiring early computers |
