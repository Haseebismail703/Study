# CS101 – Module 34 & 35

## Module 34: CPU Architecture Philosophies

### 1. Machine Language
**Definition:** Machine language is a set of instructions written in binary (0s and 1s) that a CPU can understand.

**Roman Urdu:** CPU sirf 0 aur 1 ki form mein instructions samajhta hai.

**Important:** Machine language = Binary (0 and 1).

### 2. CPU Architecture Philosophies

There are two main types:

#### A. RISC (Reduced Instruction Set Computer)

**Definition:** RISC uses a small set of simple instructions.

**Roman Urdu:** Is architecture mein kam aur simple instructions hoti hain.

**Important Points:**
- Small instruction set.
- Simple instructions.
- Fast and efficient.
- Examples: ARM, PowerPC.

#### B. CISC (Complex Instruction Set Computer)

**Definition:** CISC uses a large set of complex instructions.

**Roman Urdu:** Is architecture mein zyada aur complex instructions hoti hain.

**Important Points:**
- Large instruction set.
- Complex instructions.
- One instruction can perform complex operations.
- Example: Intel (VU handout example).

### 3. Difference Between RISC and CISC

| RISC | CISC |
|---|---|
| Small instruction set | Large instruction set |
| Simple instructions | Complex instructions |
| ARM | Intel |
| PowerPC | — |

**Remember:**
- RISC = Reduced
- CISC = Complex
- ARM = RISC
- PowerPC = RISC

## Module 35: Machine Instruction Categories

Machine instructions are divided into three main groups.

### 1. Data Transfer Group

**Definition:** Instructions that transfer data from one location to another.

**Roman Urdu:** Data ko ek jagah se doosri jagah copy karna.

**Important Instructions:**

- **LOAD:** Transfers data from Memory to CPU Register.
- **STORE:** Transfers data from CPU Register to Memory.

**Remember:**
- LOAD = Memory → Register
- STORE = Register → Memory

**Important Point:** Data transfer is more like copying because original data usually remains in its location.

### 2. I/O Instructions

**Definition:** Instructions used to communicate with input/output devices.

**Roman Urdu:** CPU ko keyboard, printer aur display jaise devices se communicate karwana.

**Examples:** Keyboard, Printer, Display, Disk Drive.

I/O = Input / Output.

### 3. Arithmetic/Logic Group

**Definition:** Instructions that perform arithmetic and logical operations.

**Roman Urdu:** CPU ke calculations aur logical operations perform karna.

**Examples:**
- Addition (+)
- Subtraction (-)
- AND
- OR
- XOR

**Important:** These operations are performed by ALU (Arithmetic Logic Unit).

### 4. Control Group

**Definition:** Instructions that control the execution of a program.

**Roman Urdu:** Program ka next step decide karna aur execution ko control karna.

**Important Instructions:**
- **JUMP:** Moves program execution to another instruction.
- **BRANCH:** Changes program direction based on a condition.
- **HALT:** Stops program execution.

**Important:** Control Group controls program execution rather than manipulating data.
