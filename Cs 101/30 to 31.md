# MODULE 30 – Data Compression: Compressing Images

## 1. Image Compression

**Definition:** Image compression reduces the size of image data.

**Roman Urdu:** Image compression picture ka file size kam karti hai taake storage space kam use ho.

**Important:** Different compression schemes are used for images.

## 2. GIF (Graphic Interchange Format)

**Definition:** GIF is a dictionary encoding system developed by CompuServe.

**Roman Urdu:** GIF images ko compress karta hai by reducing the number of colors to 256.

### Important Points

- Full form: Graphic Interchange Format.
- Developed by: CompuServe.
- Uses maximum 256 colors.
- Uses dictionary encoding.
- Uses LZW (Lempel-Ziv-Welch) techniques.
- Supports transparency.
- Suitable for simple animations.
- Not suitable for high-precision photographs.

### GIF Color System

- GIF uses a maximum of 256 colors.
- Each color is represented using 3 bytes (RGB).
- These colors are stored in a table called Palette.
- Each pixel is represented by 1 byte.

**Remember:**
- 256 colors = GIF limit.
- 3 bytes = RGB color combination.
- 1 byte = Each pixel's palette reference.
- Palette = Color dictionary.

## 3. Palette

**Definition:** A palette is a table containing the 256 color combinations used by GIF.

**Roman Urdu:** Palette ek table hoti hai jisme GIF ke colors save hote hain. Har pixel apne color ko identify karne ke liye is table ka reference use karta hai.

## 4. LZW (Lempel-Ziv-Welch Encoding)

**Definition:** LZW is an adaptive dictionary encoding technique.

**Roman Urdu:** LZW patterns ko dictionary mein add karta rehta hai. Agar wohi pattern dobara aaye toh usay dictionary reference se represent kar sakte hain.

### Important Points

- Full form: Lempel-Ziv-Welch.
- It is an adaptive dictionary encoding technique.
- The dictionary grows during encoding.
- It improves compression by storing repeated patterns as references.

### Creators of LZW

- Abraham Lempel
- Jacob Ziv
- Terry Welsh

**Remember:** LZW = Adaptive dictionary encoding.

## 5. Transparency in GIF

**Definition:** Transparency allows the background to show through a selected color.

**Roman Urdu:** GIF mein ek color transparent set kiya ja sakta hai. Is color wali jagah se background nazar aata hai.

**Use:** Simple animations.

## 6. JPEG (Joint Photographic Experts Group)

**Definition:** JPEG is a standard used for compressing color photographs.

**Roman Urdu:** JPEG photographs ka size kam karta hai. Digital cameras mein commonly use hota hai.

### Important Points

- Full form: Joint Photographic Experts Group.
- Developed within: ISO.
- Used for: Color photographs.
- Commonly used in digital cameras.
- Supports lossless and lossy compression methods.

## 7. JPEG Lossless Mode

**Definition:** Lossless mode preserves all original image information.

**Roman Urdu:** Is mode mein original image ka data lose nahi hota.

**Important:** Lossless mode provides lower compression compared to other JPEG options.

## 8. JPEG Baseline Standard

**Definition:** JPEG baseline standard is also known as lossy sequential mode.

**Roman Urdu:** Is mode mein kuch image information remove hoti hai taake file size kam ho.

### Important Points

- Also called: Lossy Sequential Mode.
- It is commonly used.
- Takes advantage of human eye limitations.
- Provides high image compression.

## 9. Human Eye Limitations

**Important Concept:**

The human eye is more sensitive to changes in brightness than changes in color.

**Roman Urdu:** Insani aankh brightness mein changes ko colors ke changes se zyada clearly notice karti hai.

**Remember:**
- Brightness = Luminance.
- Color = Chrominance.

## 10. Luminance and Chrominance

**Luminance:** Represents the brightness information of an image.

**Chrominance:** Represents the color information of an image.

**Roman Urdu:**
- Luminance batata hai image kitni bright ya dark hai.
- Chrominance image ke colors ki information rakhta hai.

## 11. JPEG Compression Steps

### Step 1: Chrominance Averaging

JPEG averages chrominance values over 2-by-2 pixel squares.

**Roman Urdu:** 2×2 pixels ke colors ki information average ki jati hai.

- Chrominance information is reduced by a factor of 4.
- Original brightness information is preserved.

### Step 2: Divide Image into Blocks

The image is divided into 8-by-8 pixel blocks.

**Roman Urdu:** Image ko chotay blocks mein divide kiya jata hai. Har block ko separately process kiya jata hai.

### Step 3: Discrete Cosine Transform (DCT)

**Definition:** DCT is a mathematical technique used to transform image blocks.

**Roman Urdu:** DCT original pixels ko transform karta hai taake unke relationships aur patterns represent ho saken.

**Remember:** DCT = Discrete Cosine Transform.

### Step 4: Thresholding

Values below a predetermined threshold are replaced by zeros.

**Roman Urdu:** Bohat choti changes jo aankh easily notice nahi kar sakti, unki values zero kar di jati hain.

### Step 5: Additional Compression

The following techniques are applied:

- Run-length encoding.
- Relative encoding.
- Variable-length encoding.

### JPEG Compression Result

JPEG baseline standard normally compresses color images:

- At least 10 times.
- Often up to 30 times.

Without noticeable loss of quality.

**Remember:** JPEG = 10 to 30 times compression.

## 12. TIFF (Tagged Image File Format)

**Definition:** TIFF is a standardized format for storing photographs and related information.

**Roman Urdu:** TIFF images ke sath date, time aur camera settings jaisi information bhi store kar sakta hai.

### Important Points

- Full form: Tagged Image File Format.
- Used for storing photographs.
- Stores related information such as date, time and camera settings.
- Usually stores RGB pixel components without compression.
- Also supports image compression techniques.

### TIFF Compression

- Uses variations of Run-Length Encoding for text documents.
- Takes advantage of long sequences of white pixels.
- Color image compression is similar to GIF.
- Not widely used in photography for color image compression.

## 13. GIF vs JPEG vs TIFF

| GIF | JPEG | TIFF |
|---|---|---|
| Maximum 256 colors | Color photographs | Photograph storage |
| Dictionary encoding | Lossy and lossless modes | Usually uncompressed |
| Uses LZW | Uses DCT | Stores related information |
| Supports transparency | Common in cameras | Stores date and time |
| Simple animations | High compression | Professional image storage |

# MODULE 31 – Data Compression: Compressing Audio and Videos

## 1. MPEG (Motion Picture Experts Group)

**Definition:** MPEG is a group of standards used for encoding and compressing audio and video.

**Roman Urdu:** MPEG audio aur video ka size kam karta hai taake storage aur transmission easy ho.

### Important Points

- Full form: Motion Picture Experts Group.
- Developed under the leadership of ISO.
- Used for audio and video compression.

## 2. Applications of MPEG

1. **HDTV (High Definition Television):** High-quality television broadcasting.
2. **Video Conferencing:** Sending video through communication channels.
3. **Video Storage:** Storing video so users can replay or skip different sections.

## 3. Video Compression

**Definition:** Video compression reduces the size of video data.

**Roman Urdu:** Video bohat saari pictures (frames) se mil kar banti hai. Compression similar pictures ka faida uthata hai aur file size kam karta hai.

## 4. I-Frames (Intra Frames)

**Definition:** I-frames are complete pictures stored in a video.

**Roman Urdu:** I-frame mein poori picture save hoti hai, sirf changes nahi.

- Complete picture is stored.
- Uses compression similar to JPEG.

**Remember:** I-frame = Complete picture.

## 5. Relative Encoding

**Definition:** Relative encoding stores only the differences between consecutive pictures.

**Roman Urdu:** Har next picture dobara complete save nahi hoti. Sirf previous picture ke comparison mein changes save hote hain.

**Remember:** Relative encoding = Only differences.

## 6. JPEG Compression in I-Frames

**Definition:** I-frames are usually compressed using techniques similar to JPEG.

**Roman Urdu:** I-frame complete picture hoti hai aur JPEG jaisi image compression technique use karti hai.

## 7. MP3 (MPEG Layer 3)

**Definition:** MP3 is a popular audio compression system developed within MPEG standards.

**Roman Urdu:** MP3 audio file ka size kam karta hai aur un sounds ko remove karta hai jo human ear normally perceive nahi kar sakta.

- Full form: MPEG Layer 3.
- Purpose: Audio compression.
- Provides near CD quality sound.

## 8. Temporal Masking

**Definition:** Temporal masking occurs when a loud sound makes softer sounds temporarily inaudible.

**Roman Urdu:** Loud sound ke baad thori dair tak halki sound human ear detect nahi kar pati.

**Remember:** Temporal = Time.

## 9. Frequency Masking

**Definition:** Frequency masking occurs when a loud sound masks softer sounds at nearby frequencies.

**Roman Urdu:** Loud frequency ki wajah se uske nearby frequencies ki halki sounds sunai nahi deti.

**Remember:** Frequency = Nearby frequencies.

## 10. Temporal Masking vs Frequency Masking

| Temporal Masking | Frequency Masking |
|---|---|
| Related to time | Related to frequency |
| Loud sound temporarily hides soft sound | Loud frequency hides nearby soft frequencies |
| Time difference | Frequency difference |

## 11. Purpose of Audio and Video Compression

Two important purposes:

1. **Storage:** Requires less storage space.
2. **Transmission:** Allows data to be transmitted efficiently and on time.

**Roman Urdu:** Compression sirf storage bachane ke liye nahi, balkay internet aur communication networks par data transfer karne ke liye bhi hoti hai.

## 12. Transmission Speed

**Definition:** Transmission speed is the rate at which data is transferred through a communication channel.

It is measured in bits per second (bps).

| Unit | Meaning |
|---|---|
| bps | Bits per second |
| Kbps | 1,000 bits per second |
| Mbps | 1,000,000 bits per second |
| Gbps | 1,000,000,000 bits per second |

## 13. Important Numerical Facts

| Fact | Value |
|---|---:|
| Video duration example | 1 hour |
| Video storage example | 128 MB |
| Popular songs in 1 GB | 400 songs |
| One video frame example | 1 MB |
| Communication path example | 1 KB per second |
| MPEG video presentation | 40 Mbps |
| MP3 recording | No more than 64 Kbps |

**Important:** These are examples from the VU handout, not universal values.
