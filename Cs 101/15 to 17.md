# Module 15 — Magnetic Systems

### Important Definitions

**1. Magnetic Storage**  
Data ko magnetic properties ki madad se store karna.  
Example: Hard Disk.

**2. Tracks**  
Disk ki surface par concentric circles ko tracks kehte hain.

**3. Sectors**  
Track ke chotay portions ko sectors kehte hain.

**4. Read/Write Head**  
Disk se data read aur disk par data write karta hai.

**5. Seek Time**  
Read/write head ko aik track se doosray track tak move karne ka time.

**6. Rotation Delay**  
Required sector ke head ke neeche aane ka waiting time.

**7. Access Time**  
Seek Time + Rotation Delay.

**8. Transfer Rate**  
Data transfer hone ki speed.

**9. Zoned-Bit Recording**  
Disk ke tracks ko zones mein divide karna; aik zone ke tracks mein sectors ki quantity same hoti hai.

**MCQ Quick Revision:**
- Hard Disk = Magnetic Storage
- Tracks = Concentric Circles
- Sectors = Parts of Tracks
- Seek Time = Head Movement
- Rotation Delay = Waiting for Sector
- Access Time = Seek Time + Rotation Delay

# Module 16 — Optical Systems

### Important Definitions

**1. Optical Storage**  
Laser light ki madad se data read karne wali storage technology.

**2. CD — Compact Disc**  
Optical storage device jo laser use karti hai.

**3. DVD — Digital Versatile Disc**  
Optical storage device jiski capacity CD se zyada hoti hai.

**4. Blu-ray**  
Optical storage technology jo blue-violet laser use karti hai.

**MCQ Quick Revision:**
- Optical Storage = Laser Light
- CD Diameter = 12 cm
- CD Capacity = 600–700 MB
- CD Sector = 2 KB
- CD Track = Single Spiral Track
- CD Track Direction = Inside to Outside
- DVD Capacity = GBs
- Blu-ray = Blue-Violet Laser
- Blu-ray Capacity = DVD se approximately 5 times

# Module 17 — Flash Drives

### 17.1 Issues in Magnetic and Optical Systems

Magnetic aur optical systems mein physical movement ki zaroorat hoti hai, jis se data access mein time lagta hai.

### 17.2 Flash Drive Technology

**Flash Memory:** Electronic signals ki madad se data store karne ki technology.

**Important Facts:**
- Electrons silicon dioxide ke tiny chambers mein store hotay hain.
- Data external power ke baghair years tak store reh sakta hai.
- Repeated erasing silicon dioxide chambers ko damage karti hai.
- Flash drives cameras aur smartphones mein use hoti hain.

### 17.3 SSDs

**Full Form:** Solid State Disks

**Definition:** Larger flash memory devices designed to replace magnetic disks.

**Important Facts:**
- SSD uses flash memory.
- Low access time.
- Quiet operation.
- Magnetic disks se more costly.

### 17.4 SD Cards

**Full Form:** Secure Digital Memory Cards

**Important Facts:**
- Standard, Mini aur Micro sizes.
- Cameras aur portable devices mein use hotay hain.

**SDHC:** Secure Digital High Capacity  
- Capacity up to 32 GB.

**SDXC:** Secure Digital Extended Capacity  
- Capacity greater than 32 GB.
