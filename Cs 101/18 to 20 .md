# CS101 – Modules 18 to 20
## Important Points for Midterm Revision

## Module 18 – Representing Text

### 18.1. Representation as Code
- Each textual symbol is represented with a unique bit pattern.
- Normally, 8 bits are used for each character.
- 8 bits = 1 byte.
- Example: "Virtual University" contains 18 characters.
- 18 × 8 = 144 bits or 18 bytes.
- ANSI = American National Standards Institute.
- ASCII = American Standard Code for Information Interchange.

### 18.2. ASCII Codes
- ASCII uses 7 bits for information.
- Most significant bit (MSB) is zero.
- 2⁷ = 128 combinations.
- ASCII represents uppercase letters, lowercase letters, punctuation marks, digits (0–9), line feed, carriage returns and tabs.

### 18.3. ASCII Code Example
- ASCII assigns a numeric code to each character.
- Example: Each letter in "Hello" has its own ASCII code.

### 18.4. Limitation of ASCII Codes
- ASCII supports only 128 characters.
- ISO = International Organization for Standardization.
- ISO introduced extensions to ASCII.
- One extension supported Western language symbols.

### 18.5. Limitations of ASCII-Extensions
- 256 characters were still insufficient for all language symbols.
- Documents containing multiple languages could face compatibility problems.

### 18.6. Unicode
- Unicode was introduced to support international characters.
- Uses unique patterns of 21 bits (as described in the handout).
- Compatible with ASCII.
- Supports thousands of character sets, including Chinese, Hebrew and Japanese.

### 18.7. UTF-8
- UTF-8 uses 24 to 32 bits (according to the handout).
- Provides large possibilities for expansion.
- 2²⁴ = 16,777,216 unique symbols.
- A file consisting of text symbols encoded with ASCII or Unicode is called a text file.

**Important MCQ Facts:**
- Normal character storage → 8 bits.
- 1 byte → 8 bits.
- ASCII information bits → 7 bits.
- ASCII combinations → 128.
- ASCII extension → 256 characters.
- ANSI → American National Standards Institute.
- ASCII → American Standard Code for Information Interchange.
- ISO → International Organization for Standardization.
- Unicode → 21-bit unique patterns.
- UTF-8 → 24 to 32 bits (handout).

## Module 19 – Representing Numeric Values

### 19.1. Issues in Storing Numeric as Unicode
- Storing numeric values as Unicode can be inefficient.
- Example: To store 12 as two Unicode characters, 16 bits are required.
- 99 can also be stored in 16 bits.
- 16 bits can represent 2¹⁶ = 65,536 different patterns.

### 19.2. Binary Notation
- Binary notation represents numeric values using only 0 and 1.
- Decimal system uses digits 0 to 9.
- Binary system uses base 2.

**3-bit Representation:**

| 1 | 001 |
| 2 | 010 |
| 3 | 011 |
| 4 | 100 |

| 7 | 111 |

**Important Formula:**

Number of possible patterns = 2ⁿ

Where:
- n = Number of bits.

Examples:
- 1 bit = 2 values.
- 3 bits = 2³ = 8 values.
- 4 bits = 2⁴ = 16 values.
- 8 bits = 2⁸ = 256 values.
- 16 bits = 2¹⁶ = 65,536 values.

### 19.3. Binary Notation Variations
Binary notation has two representations:

1. **Two's Complement:** Used for storing whole numbers (including negative numbers).
2. **Floating Point Notation:** Used for storing fractional numbers.

**Important MCQ Facts:**

- Formula → 2ⁿ.
- Two's Complement → Whole numbers.
- Floating Point → Fractional numbers.

## Module 20 – Representing Images

### 20.1. Pixel
- Pixel is short for Picture Element.
- An image is made up of a collection of dots called pixels.
- Appearance of each pixel is encoded to form a bitmap.
- Many display devices and printers work on the pixel concept.

### 20.2. Encoding Method: Pixel to Bitmap
- In black and white images, each pixel is represented using 1 bit.
- 0 represents black.
- 1 represents white.
- Often used in Facsimile (Fax).

### 20.3. Encoding Method: Handling Shades
- 8 bits are used instead of 1 bit to store shades of grayness.
- 8 bits can represent 256 different values.

### 20.4. Encoding Method: Colorful Images
- RGB encoding is used.
- RGB stands for Red, Green and Blue.
- One byte is used for Red.
- One byte is used for Green.
- One byte is used for Blue.
- Total = 3 bytes (24 bits) per pixel.

### 20.5. Brightness Chrominance
- Uses one brightness component and two color components.
- Brightness component = Pixel's luminance.
- Luminance is related to the combination of red, green and blue.
- Blue Chrominance and Red Chrominance represent color differences.

### 20.6. Image Scaling
- Scaling means changing the size of an image.
- Scaling to a larger size needs more pixels.
- Digital Zoom is related to image scaling.

### 20.7. Geometric Structures for Image Scaling
- Uses a collection of lines and curves.
- Uses Analytical Geometry.
- Focuses on displaying geometric structures rather than reproducing individual pixels.

### 20.8. Scalable Fonts
- TrueType was developed by Microsoft and Apple.
- PostScript was developed by Adobe.
- These are also popular in Computer Aided Design (CAD).

**Important MCQ Facts:**
- Pixel → Picture Element.
- Bitmap → Collection of encoded pixels.
- Black and White → 1 bit per pixel.
- 0 → Black.
- 1 → White.
- Gray shades → 8 bits.
- RGB → Red, Green, Blue.
- RGB storage → 3 bytes per pixel.
- Brightness → Luminance.
- Image scaling → Changing image size.
- TrueType → Microsoft and Apple.
- PostScript → Adobe.
- CAD → Computer Aided Design.
