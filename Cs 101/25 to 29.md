## Module 25 – 2's Complement

**Purpose:** Positive aur negative integers ko Binary mein represent karna.

- Negative numbers represent karne ka method.
- Fixed number of bits use hote hain.
- Leftmost bit = Sign bit.
- `0` = Positive, `1` = Negative.

### Negative number banane ke steps

1. Positive number ka Binary banao.
2. Sab bits invert karo (0 → 1, 1 → 0).
3. Right side par `1` add karo.

**Example: 4-bit mein -5**

```text
+5 = 0101
Invert = 1010
Add 1 = 1011
```

### Important Points

- 2's Complement mein addition normal Binary addition se hoti hai.
- Overflow = Jab result available bits mein store na ho sake.
- 4-bit range: `-8` to `+7`.
- Example: `5 + 4 = 9` 4 bits mein represent nahi ho sakta.

### Quiz Highlights

- 2's Complement is used for negative numbers.
- Leftmost bit is called Sign bit.
- Overflow occurs when result exceeds the available range.
- Computers commonly use 32-bit representation.

## Module 26 – Excess Notation

**Purpose:** Signed integers ko represent karne ka another method.

### Main Rule

- Decimal → Excess = PLUS (+)
- Excess → Decimal = MINUS (-)

### Important Excess Values

| Notation | Bits | Zero |
|---|---:|---|
| Excess 4 | 3 | `100` |
| Excess 8 | 4 | `1000` |
| Excess 16 | 5 | `10000` |

### Example 1: Decimal → Excess 4

```text
-2 + 4 = 2
2 = 010
Answer = 010
```

### Example 2: Excess 4 → Decimal

```text
110 = 6
6 - 4 = +2
Answer = +2
```

### Excess 4 Important Table

| Binary | Decimal |
|---|---:|
| 111 | +3 |
| 110 | +2 |
| 101 | +1 |
| 100 | 0 |
| 011 | -1 |
| 010 | -2 |
| 001 | -3 |
| 000 | -4 |

### Quiz Highlights

- Excess 4 represents zero as `100`.
- Excess 8 represents zero as `1000`.
- Excess 8: `1011` represents `+3`.
- Fixed number of bits are used.
- Excess 4 and Excess 8 bit patterns mein confusion na karna.

## Module 27 – Floating Point Notation

**Purpose:** Decimal/fractional numbers ko Binary mein store karna.

### Three Important Parts

| Part | Meaning |
|---|---|
| Sign | Positive / Negative |
| Exponent | Radix point ki position |
| Mantissa | Number ke Binary digits |

### VU 8-bit Example Format

```text
1 bit = Sign
3 bits = Exponent
4 bits = Mantissa

Total = 8 bits
```

### Sign

- `0` = Positive
- `1` = Negative

### Exponent

- Is format mein Excess 4 use hota hai.
- `110` = +2
- `100` = 0
- `011` = -1

### Mantissa

- Binary point mantissa ke left par lagao.
- Positive exponent = Point Right.
- Negative exponent = Point Left.

### Example

```text
01101011

Sign = 0
Exponent = 110 = +2
Mantissa = 1011

.1011 → 10.11

Answer = +2.75
```

### Important Points

- Floating Point stores fractional values.
- Radix point ki position bhi store hoti hai.
- Non-zero normalized mantissa 1 se start hoti hai.
- Zero ka special representation all bits zero hai.

### Quiz Highlights

- Sign, Exponent aur Mantissa ke functions.
- 8-bit format = 1 + 3 + 4 bits.
- Excess 4 exponent decoding.
- Positive/negative exponent se point movement.
- Binary fraction ko Decimal mein convert karna.

## Module 28 – Truncation Errors

**Definition:** Jab computer ki limited storage ki wajah se number ke kuch digits store nahi ho paate, toh Truncation Error hota hai.

### Example

```text
Original = 10.101
Stored   = 10.10
```

Last `1` store nahi hua, isliye value change ho gayi.

### Important Terms

- **Truncation Error:** Digits lost due to limited space.
- **Roundoff Error:** Limited precision ki wajah se stored value mein difference.
- **Longer Mantissa:** More precision.
- **Primitive Method:** Mantissa ko longer karna.
- **Intelligent Processing:** Calculation ka order smartly choose karna.

### Intelligent Processing Example

Pehle small values add karo, phir large value ke saath add karo. Isse kuch truncation errors avoid ho sakte hain.

### Quiz Highlights

- Limited Mantissa causes truncation.
- Longer Mantissa improves accuracy.
- Binary `1/10` ki representation non-terminating hoti hai.
- Addition order can affect accuracy.
- Small quantities ko pehle add karna useful ho sakta hai.

## Module 29 – Data Compression: Generic Techniques

**Purpose:** Data ka file size kam karna.

### Two Main Types

| Type | Meaning |
|---|---|
| Lossless | Original information lost nahi hoti |
| Lossy | Kuch information lose ho sakti hai |

### Important Techniques

**1. Run-Length Encoding (RLE)**

Repeated values ko count ke saath store karta hai.

Example:

```text
11110000
Four 1s + Four 0s
```

**2. Frequency-Dependent Encoding**

Frequently used values ko short codes deta hai.

**3. Huffman Coding**

- Frequency-dependent encoding ka popular method.
- Developed by David Huffman.

**4. Relative / Differential Encoding**

Previous data ke comparison mein sirf differences store karta hai.

**5. Dictionary Encoding**

Repeated words ya patterns ko dictionary references se represent karta hai.

### Quiz Highlights

- RLE = Repeated data + count.
- Huffman = David Huffman.
- Frequently used characters = Short codes.
- Relative Encoding = Differences store karta hai.
- Lossless = No information loss.
- Lossy = Information loss possible.

## Module 30 – Data Compression: Compressing Images

**Purpose:** Image quality ko acceptable rakhte hue file size reduce karna.

### Important Image Formats

| Format | Important Point |
|---|---|
| GIF | Maximum 256 colors |
| JPEG | Color photographs compression |
| TIFF | Tagged Image File Format |

### GIF

- Full form: Graphic Interchange Format.
- 256 colors use karta hai.
- Palette = Colors ki table.
- Dictionary encoding / LZW techniques use karta hai.
- Transparency aur simple animations support karta hai.
- Arbitrary images mein colors approximate hon toh lossy ho sakta hai.

### JPEG

- Full form: Joint Photographic Experts Group.
- Color photographs ke liye popular.
- Lossy compression.
- 8 × 8 pixel blocks use karta hai.
- DCT = Discrete Cosine Transform.
- Normally 10 to 30 times compression achieve kar sakta hai.

### TIFF

- Full form: Tagged Image File Format.
- Photos ke saath date, time aur camera settings store kar sakta hai.
- Commonly RGB components ke saath uncompressed images store karta hai.
- Text documents ke liye RLE variations use karta hai.

### Quiz Highlights

- GIF = 256 colors.
- GIF = Palette and LZW.
- JPEG = Joint Photographic Experts Group.
- JPEG = DCT.
- DCT works on 8 × 8 pixel blocks.
- TIFF = Tagged Image File Format.
- JPEG is lossy compression.
