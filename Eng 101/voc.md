## 7. Definition likhne ke ready-made sentence patterns

**Pattern 1:**
X refers to a process which is used to perform a specific task.

X aik aise amal ko kehte hain jo khaas kaam karne ke liye istemal hota hai.

**Pattern 2:**
X is defined as a system that allows users to perform different operations.

X aik aisa nizam hai jo users ko mukhtalif kaam karne ki ijazat deta hai.

**Pattern 3:**
X consists of different components such as A, B and C.

X mukhtalif components par mushtamil hota hai, jaisay A, B aur C.

**Pattern 4:**
X is important because it helps to improve the performance of a system.

X important hai kyun ke ye system ki performance behtar banata hai.

**Pattern 5:**
Although X has some limitations, it is useful in many situations.

Agarche X ki kuch limitations hain, lekin ye bohat si situations mein faidemand hai.
