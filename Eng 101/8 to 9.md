# ENG101 — Lesson 8 & 9 Important Notes

## Lesson 8 — Word Formation: Prefixes

### 1. Prefix

**Definition:** A prefix is a letter or group of letters added to the beginning of a word.

**Roman Urdu:** Prefix aik letter ya letters ka group hota hai jo word ke shuru mein lagta hai aur uska meaning change karta hai.

Examples:
- Happy → Unhappy (Khush → Na-khush)
- Legal → Illegal (Qanooni → Ghair-qanooni)
- Trust → Distrust (Bharosa → Be-aitemadi)

### 2. Stem / Base Word

**Definition:** The main part of a word to which prefixes or suffixes are added.

**Roman Urdu:** Word ka asal ya bunyadi hissa jiske saath prefix ya suffix lagaya jata hai.

Example:
- Unhappy → Un = Prefix, Happy = Stem
- Disagree → Dis = Prefix, Agree = Stem

### 3. Affixes

**Definition:** Prefixes and suffixes are called affixes.

**Roman Urdu:** Prefix aur suffix dono ko mila kar Affixes kehte hain.

- Prefix = Word ke shuru mein lagta hai.
- Suffix = Word ke aakhir mein lagta hai.

## Lesson 9 — Reading: Description, Locating Information

### 1. Reading Comprehension

**Definition:** Reading comprehension means understanding the meaning and information given in a passage.

**Roman Urdu:** Passage ko parh kar uska meaning aur information samajhna.

### 2. Description

**Definition:** Description provides information about the characteristics or features of something.

**Roman Urdu:** Kisi cheez ki khasusiyat, features ya working ko explain karna.

### 3. Input, Processing and Output

| Term | English Meaning | Roman Urdu Meaning |
|---|---|---|
| Input | Data given to a computer | Computer ko data dena |
| Processing | Operations performed on data | Data par kaam karna |
| Output | Result produced by a computer | Computer se result milna |

**Example: Clothing Manufacturing**

- Input = Cut pieces of cloth (Kapray ke katay huay tukray)
- Processing = Sewing the pieces (Tukron ko silna)
- Output = Finished garment (Tayyar kapra)

### 4. CPU and Memory

**CPU (Central Processing Unit)**

Definition: The central component of a computer where calculations and data manipulation are performed.

Roman Urdu: Computer ka central hissa jahan calculations aur data par processing hoti hai.

**Peripheral Devices**

Definition: Devices attached to the CPU, such as keyboards and card readers.

Roman Urdu: Aise devices jo computer ke saath connect hotay hain, jaise keyboard aur card reader.

**Secondary Memory**

Definition: Devices used to store data and programs for a long period.

Roman Urdu: Aisi storage jahan data aur programs ko lambi muddat tak save kiya jata hai.

Examples:
- Magnetic tapes = Magnetic tape par data save karna.
- Magnetic disks = Magnetic disk par data save karna.

### 5. Characteristics of Computers

| English Word / Phrase | Roman Urdu Meaning |
|---|---|
| High Speed | Bohat tez raftaar |
| Accuracy | Durustgi |
| Versatility | Mukhtalif kaam karne ki salahiyat |
| Storage | Data mehfooz rakhna |
| Processing | Data par kaam karna |
| Calculations | Hisab kitab |
| Data Manipulation | Data mein tabdeeli ya us par kaam |
| Routine Tasks | Roz marrah ke kaam |

**Important:** Versatility means the ability to perform many different types of tasks.

Roman Urdu: Computer ki versatility ka matlab hai ke woh mukhtalif qisam ke kaam kar sakta hai.

### 6. Locating Information

**Definition:** Locating information means finding specific information in a given passage.

**Roman Urdu:** Passage mein se koi khaas information, date, naam ya fact dhoondhna.

Examples:
- What is processing? (Processing kya hai?)
- Which component is the central part of a computer? (Computer ka central hissa konsa hai?)
- Where are programs stored for a long period? (Programs lambi muddat ke liye kahan save hotay hain?)

### 7. Contextual Reference

**Definition:** Contextual reference means identifying the word or idea to which another word refers in a passage.

**Roman Urdu:** Passage mein he, it, they jaise words kis person ya cheez ke liye use huay hain, ye pehchanna.

Example:

"Computers process data. They work at high speed."

- They = Computers
- Roman Urdu: They ka matlab yahan Computers hai.

### 8. Organizing Information

**Definition:** Organizing information means arranging ideas and details in a clear and meaningful order.

**Roman Urdu:** Information ko aik munazzam aur samajhne wali tarteeb mein rakhna.

### 9. Main Idea

**Definition:** The main idea is the most important idea of a paragraph.

**Roman Urdu:** Paragraph ka sab se important khayal ya central point.

### 10. Major Details

**Definition:** Major details support and explain the main idea.

**Roman Urdu:** Aham points jo main idea ko support aur explain karte hain.

### 11. Minor Details

**Definition:** Minor details provide additional information about major details.

**Roman Urdu:** Mazeed choti details jo major details ko explain karti hain.

**Example:**

Main Idea: Computers are useful because of their speed and memory.

Roman Urdu: Computers apni speed aur memory ki wajah se mufeed hain.

Major Details:
1. Computers solve problems quickly. (Computer maslay jaldi hal karte hain.)
2. Computers store information. (Computer information save karte hain.)

Minor Details:
1. Businesses use computers to maintain accounts. (Businesses hisaab kitab ke liye computers use karte hain.)
2. Airlines use computers to manage ticket sales. (Airlines tickets manage karne ke liye computers use karti hain.)

### 12. Word Forms

**Definition:** Word forms are different forms of the same word.

**Roman Urdu:** Aik hi word ki mukhtalif forms ko word forms kehte hain.

| Basic Word | Other Forms | Roman Urdu Meaning |
|---|---|---|
| Imagine | Imagination, imaginative, imaginary | Sochna, tasawwur |
| Add | Addition, additional, additive | Jama karna, izafa |
| Complicate | Complication, complicated | Mushkil banana, pecheedgi |
| Differ | Difference, different, differently | Farq hona, mukhtalif |
| Rely | Reliable, reliability, reliably | Bharosa karna, qabil-e-bharosa |

- Input = Computer ko data dena.
