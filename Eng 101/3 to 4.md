# ENG101 — Lesson 3: Reading for Main Idea

## 1. Reading Skills
**Definition:** Reading skills help us read a text quickly and understand it accurately.

**Roman Urdu:** Reading skills ka matlab hai text ko sahi aur jaldi parhna aur uska meaning samajhna.

**Important Points:**
- Read accurately to understand correct information.
- Read rapidly to save time.
- Regular practice improves reading skills.

## 2. Topic of a Paragraph
**Definition:** Topic is the subject of the whole paragraph. It tells us what the paragraph is about.

**Roman Urdu:** Topic batata hai ke poora paragraph kis cheez ke bare mein hai.

**Example:** If a paragraph discusses plants, its topic is Plants.

## 3. Main Idea
**Definition:** Main idea is the most important point or message of a paragraph.

**Roman Urdu:** Main idea paragraph ka central message hota hai. Writer asal mein kya samjhana chahta hai.

**Example:**
- Topic: Computers
- Main Idea: Computers are useful in our daily lives.

## 4. Supporting Details
**Definition:** Supporting details are facts, examples, and explanations that support the main idea.

**Roman Urdu:** Supporting details woh information hoti hai jo main idea ko explain ya prove karti hai.

**Example:**

Main Idea: Computers are useful.
- Computers are used in hospitals.
- Computers are used in schools.
- Computers are used in banks.

## Important Difference

| Topic | Main Idea | Supporting Details |
|---|---|---|
| Subject | Central message | Facts and examples |
| Computers | Computers help us in daily life | Used in banks, schools, hospitals |

## Important Keywords
- Topic = Subject
- Main Idea = Central Point
- Supporting Details = Facts / Examples
- Accurate Reading = Correct understanding
- Rapid Reading = Reading quickly

# ENG101 — Lesson 4: Reading: Topic, Main Idea

## 1. Identifying the Topic
**Definition:** Identifying the topic means finding the subject discussed in a paragraph.

**Roman Urdu:** Paragraph ko read karke pata lagana ke ye kis subject ke bare mein hai.

## 2. Identifying the Main Idea
**Definition:** The main idea explains the most important information about the topic.

**Roman Urdu:** Topic sirf subject batata hai, jabke main idea us subject ke bare mein writer ka main message batata hai.

## 3. Identifying Supporting Ideas
**Definition:** Supporting ideas provide additional information to explain the main idea.

**Roman Urdu:** Ye main idea ko samjhane ke liye extra facts aur examples deti hain.

## 4. What is a Computer?

**Definition:** A computer is an electronic machine that processes information.

**Roman Urdu:** Computer ek electronic machine hai jo data receive karti hai, us par processing karti hai aur result deti hai.

### Important Points
- A computer accepts information as input.
- It processes data and instructions.
- It provides results as output.
- It stores information in memory.
- It performs arithmetic and logical operations.
- It makes comparisons according to instructions.

## 5. Basic Computer Terms

| Term | Easy Meaning | Roman Urdu |
|---|---|---|
| Input | Information given to a computer | Computer ko di jane wali information |
| Processing | Working on information | Information par kaam karna |
| Output | Result produced by a computer | Computer ka diya hua result |
| Data | Raw facts and figures | Kacha data |
| Program | Instructions given to a computer | Computer ko di gayi instructions |
| Memory | Place where information is stored | Jahan information store hoti hai |

## 6. Arithmetic Operations
**Definition:** Arithmetic operations are mathematical calculations performed by a computer.

**Examples:**
- Addition (+)
- Subtraction (-)
- Multiplication (×)
- Division (÷)

**Roman Urdu:** Computer basic maths calculations perform kar sakta hai.

## 7. Logical Operations
**Definition:** Logical operations help a computer compare values.

**Examples:**
- Greater than (>)
- Less than (<)
- Equal to (=)

**Roman Urdu:** Computer numbers ko compare kar sakta hai, jaise konsa number bara ya chota hai.

## Important Keywords
- Computer = Electronic machine
- Input = Data entered
- Processing = Working on data
- Output = Result
- Memory = Storage
- Program = Instructions
- Arithmetic = Mathematical calculations
- Logical Operations = Comparisons
