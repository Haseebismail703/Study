# STA301 — Lecture 4: Continuous Variables
## Short Revision Notes, Formulas and Calculations

## 1. Continuous Variable

**Definition:** A continuous variable can take any value within a given interval.

**Important Points:**
- Values can include decimals.
- Examples: Height, weight, temperature.
- Graphs: Histogram, Frequency Polygon, Frequency Curve.

**Roman Urdu:** Continuous variable ki value decimal mein bhi ho sakti hai, jaise 5.5 feet ya 5.75 feet.

## 2. Construction of a Frequency Distribution

**Definition:** A frequency distribution organizes data into classes and shows the number of observations in each class.

**Important Points:**
- Find the smallest and largest values.
- Calculate the range.
- Select the number of classes.
- Calculate class interval.
- Prepare class limits and frequencies.

### 2.1 Range

**Definition:** Range is the difference between the largest and smallest values.

**Formula:**

Range = Largest Value − Smallest Value

**Calculation:**

Largest value = 44.9

Smallest value = 30.1

Range = 44.9 − 30.1 = **14.8**

**Roman Urdu:** Sab se bari value mein se sab se choti value minus karo.

### 2.2 Number of Classes

**Definition:** Number of classes is the total number of groups used to organize data.

**Important Points:**
- If the question gives the number of classes, use that number.
- Otherwise, follow the method or instructions given in the question.

### 2.3 Class Interval (h)

**Definition:** Class interval is the width of a class.

**Formula:**

h = Range ÷ Number of Classes

**Calculation:**

Range = 14.8

Number of classes = 5

h = 14.8 ÷ 5 = 2.96

Approximate class width = **3**

**Roman Urdu:** Range ko classes ki tadaad se divide karo.

## 3. Class Limits and Class Boundaries

**Definition — Class Limits:** The lowest and highest values stated for a class.

**Definition — Class Boundaries:** The actual dividing points between adjacent classes, adjusted to remove gaps where necessary.

**Important Points:**
- Lower limit = Starting value of a class.
- Upper limit = Ending value of a class.
- For whole-number data, boundaries are commonly adjusted by 0.5.

**Example:**

Class interval = 30–34

- Lower limit = 30
- Upper limit = 34
- Lower boundary = 30 − 0.5 = 29.5
- Upper boundary = 34 + 0.5 = 34.5

Class boundaries = **29.5–34.5**

**Note:** For data recorded to one decimal place, the boundary adjustment may be 0.05 instead of 0.5.

## 4. Frequency (f)

**Definition:** Frequency is the number of observations in a class.

**Important Points:**
- Symbol = f
- Total frequency = N
- The sum of all class frequencies equals the total number of observations.

**Example:** If 6 observations fall in a class, its frequency is 6.

## 5. Relative Frequency

**Definition:** Relative frequency is the proportion of total observations belonging to a class.

**Important Points:**
- Divide class frequency by total frequency.
- The sum of relative frequencies is 1.

**Formula:**

Relative Frequency = f/N

**Calculation:**

Class frequency = 6

Total frequency = 30

Relative Frequency = 6/30 = **0.20**

**Roman Urdu:** Class ki frequency ko total frequency se divide karo.

## 6. Percentage Frequency

**Definition:** Percentage frequency shows the percentage of total observations in a class.

**Important Points:**
- Multiply relative frequency by 100.
- Total percentage frequency is 100%.

**Formula:**

Percentage Frequency = Relative Frequency × 100

**Calculation:**

= 0.20 × 100

= **20%**

## 7. Mid-point (Class Mark)

**Definition:** The midpoint is the middle value of a class interval.

**Important Points:**
- It represents the centre of the class.
- It is used on the X-axis of a frequency polygon.

**Formula:**

Mid-point = (Lower Limit + Upper Limit) ÷ 2

**Calculation:**

Class interval = 30–34

Mid-point = (30 + 34) ÷ 2

= 64 ÷ 2

= **32**

**Roman Urdu:** Dono limits ko add karke 2 se divide karo.

## 8. Histogram

**Definition:** A histogram represents a frequency distribution using adjacent rectangles.

**Important Points:**
- X-axis = Class boundaries.
- Y-axis = Frequencies.
- Rectangles are adjacent, with no gaps.
- Each rectangle represents a class.

**Roman Urdu:** Histogram mein bars ke darmiyan gap nahi hota.

**MCQ Keyword:** Class boundaries.

## 9. Frequency Polygon

**Definition:** A frequency polygon is a graph formed by joining class midpoint-frequency points with straight lines.

**Important Points:**
- X-axis = Class midpoints.
- Y-axis = Frequencies.
- Join plotted points using straight lines.
- Add suitable zero-frequency endpoints to close the polygon.

**Example:**

| Mid-point | Frequency |
|---:|---:|
| 32 | 4 |
| 36 | 7 |
| 40 | 5 |

Plot the points (32, 4), (36, 7), and (40, 5), then join them.

**Roman Urdu:** Midpoints ke against frequencies plot karke straight lines se join karte hain.

**MCQ Keyword:** Class midpoints.

## 10. Frequency Curve

**Definition:** A frequency curve is a smooth curve representing a frequency distribution.

**Important Points:**
- It shows the general shape of a frequency distribution.
- It is smoother than a frequency polygon.

**Roman Urdu:** Frequency polygon ki jagged lines ki jagah smooth curve ban jati hai.

## 11. Difference Between Graphs

| Graph | X-axis / Main Feature |
|---|---|
| Histogram | Class boundaries; adjacent rectangles |
| Frequency Polygon | Class midpoints; straight lines |
| Frequency Curve | Smooth curve |

## 12. Formulas to Memorize

**Ye formulas exam revision ke liye ek jagah yaad karo.**

1. **Range**

   Range = Largest Value − Smallest Value

2. **Class Interval**

   h = Range ÷ Number of Classes

3. **Lower Class Boundary** (whole-number data)

   Lower Boundary = Lower Limit − 0.5

4. **Upper Class Boundary** (whole-number data)

   Upper Boundary = Upper Limit + 0.5

5. **Relative Frequency**

   RF = f/N

6. **Percentage Frequency**

   Percentage Frequency = (f/N) × 100

7. **Mid-point / Class Mark**

   Mid-point = (Lower Limit + Upper Limit) ÷ 2

8. **Total Frequency**

   Σf = N

9. **Sum of Relative Frequencies**

   Σ(f/N) = 1

10. **Sum of Percentage Frequencies**

    Total Percentage Frequency = 100%

### Symbols to Remember

- **f** = Frequency of a class
- **N** = Total frequency / total observations
- **h** = Class interval width
- **Σ** = Sum of all values
